## 2. 直接可用的三条论断（有 A-摘要支持）

1. 样本量不足会使 ML 研究的结论不稳定，且精度随样本量存在边际递减（文献 3）。
2. 非线性 ML 模型无法用经典功效公式解析计算，需要用近似/模拟方法（文献 4）——
   这正是我们做**蒙特卡洛功效分析**的依据。
3. 数据泄漏会系统性高估性能，且"按键式"使用会放大该风险（文献 5）。

## 5. PHME 2026 全文关键点（已读）
+
+- 基准：CWRU + Paderborn；6 个固定 source-target 场景；**recording-level 划分**。
+- 结论：场景难度异质；DL 对初始化敏感（需重复种子）；建议用 ROC/AUROC 而非 accuracy。
+- 对我们的直接影响：
+  1. "泄漏安全划分 / recording-level 分离"**已经是既有工作**，不能再作为我们的创新点；
+  2. 但该文**没有做统计功效分析**，也**没有报告"看似显著但不复现"的实例**——
+     这正是我们的增量边界；
+  3. 它引用 Vieira 等（MSSP 2026）说明"物理上有意义的划分会改变性能"，
+     进一步印证我们必须与该文对话，而不是重复其结论。

## 6. Vieira 2026 全文关键点与我们的增量（已读 40 页）
+
+**该文做了什么**：数据泄漏审计 + bearing-wise 划分 + 多标签重构 + ROC 指标 + 轴承数量对泛化的影响；四个数据集验证。
+
+**该文没有做什么（关键词 0 命中）**：无监督/单类检测、仅健康数据训练、统计功效、样本量。
+
+**因此我们的贡献边界（定稿）**：
+
+> 在**只有健康数据可训练**的低成本监测场景下，研究**单类/无监督检测器**的评价可靠性：
+> (i) 评价单元应为记录/批次而非窗口；(ii) 报告统计功效与所需样本量；
+> (iii) 公开一个"单数据集上看似显著、跨批次不复现"的实例。
+
+**必须避免的写法**：不得声称"我们首次发现泄漏问题"或"首次提出泄漏安全划分"。
