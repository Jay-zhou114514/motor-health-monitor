# V1.4 功效分析（规划用）

- 日期：2026-09-16
- 脚本：`src/plan_power_analysis.py`
- 数据：`docs/plans/power_analysis.csv`、`docs/plans/figures/power_curves.png`
- 方法依据：statistical-power skill（先导效应量 + 蒙特卡洛 + 敏感性分析 + MC 置信区间）

## 1. 设计

分析单元 = **正常文件**（文件级配对比较），因此不存在"窗口伪重复"问题。

- 检验：配对 t 检验（等价于单样本 t 检验，比较每对文件的差异）
- α = 0.05（双侧），目标功效 = 0.80
- 蒙特卡洛：5000 次/点；要求功效的 n 值用 2000 次/点扫描

## 2. 效应量（来自 EXP-V1-06 实测，属先导估计）

| 假设 | 每折差异 | 均值 | SD | Cohen's dz |
| --- | --- | ---: | ---: | ---: |
| H1 几何归因（问题组 s − 对照组 s） | +1.317, +0.011, −0.054 | 0.424 | 0.774 | **0.549** |
| H2 正则化（经验协方差膨胀比 − 收缩后） | +1.265, +0.050, +0.544 | 0.620 | 0.611 | **1.014** |

注意：H1 的差异由单折（F1）主导，均值/标准差本身极不稳定——这正是它功效低的原因。

## 3. 结果：达到 80% 功效所需的正常文件数

| 效应量 dz | 所需正常文件数 |
| ---: | ---: |
| 0.30 | 90 |
| 0.40 | 51 |
| **0.549（H1 实测）** | **29** |
| 0.70 | 19 |
| **1.014（H2 实测）** | **10** |

当前 3 个正常文件下的实际功效：

| 假设 | 功效 | 95% 蒙特卡洛 CI |
| --- | ---: | --- |
| H1 | **0.087** | 0.079–0.095 |
| H2 | **0.180** | 0.170–0.191 |

## 4. 含义（对本项目决策的直接后果）

1. **EXP-V1-06 的 H1 阴性结果不是反驳，而是"无法判定"。**
   在功效 0.087 的设计下，即使 H1 为真，也有约 91% 的概率观察到"未复现"。
   因此 H1 的判定应从"复现性不足（Level C）"改为
   **"功效不足，无法判定（inconclusive due to low power）"**。
2. **H2 的效应更大（dz ≈ 1.0），所需样本 10 个文件——比 H1 现实得多**，
   是当前更值得推进的主线。
3. 要在本数据集内检验 H1，需要约 29 个正常文件；当前只有 3 个 → 不可行。
   可行路径是引入**第二个公开数据集**里的大量正常记录。
4. 该分析本身构成本项目的一条方法学结论：
   **在严格评估下报告阴性结果前，必须先报告设计的功效**——否则会把"没看见"当成"不存在"。

## 5. 对下一实验的约束

- H2 的跨数据集验证：至少 **10 个正常文件**（≥ 两个数据集），以 80% 功效检验 dz ≈ 1.0。
- H1 若仍要检验：需要约 **29 个正常文件** + 预先注册的判据；否则不宣称其成立或不成立。
- 所有新实验必须在预注册中写明：设计、效应量假设、目标功效、所需文件数。
