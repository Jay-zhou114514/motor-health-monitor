## 一、当前研究阶段定位

项目已从"建立一个轴承故障检测项目"转向研究：**简单、可解释的马氏距离异常检测器，在严格评估与小样本条件下为什么会产生大量误报，以及这种失败是否与高相关特征导致的协方差估计不稳定有关。**

## 二、已确认事实（Evidence Level A）

仅列出在本数据集内已有受控实验支持的事实：

1. 故障检测本身很容易：在所有特征组合下召回率都等于 1.000（EXP-V1-02）。
2. 方法 A（RMS 3σ）在 k = 2.5~4 区间内结果完全一致，仅 k = 2 时出现 1 个误报（EXP-V1-01）。
3. 方法 B（马氏距离）对阈值不敏感：分位数从 0.90 到 0.999，所有指标完全不变（EXP-V1-01）。
4. 特征越多，误报越多：RMS only = 1，加峭度或峰均比 = 2，加谱质心 = 8，四个特征 = 9（EXP-V1-02）。
5. 误报分散在整段记录（9/11 窗口），距离贡献主要来自 RMS（59.1%）与谱质心（32.5%）（EXP-V1-03）。
6. 删除 RMS 或谱质心后误报从 9 降到 2~3；删除峰均比或峭度几乎无改善（EXP-V1-03-D）。
7. 四特征协方差条件数：训练 3.8×10⁹、baseline_3 2.0×10¹⁰；而 rms+kurtosis 仅 1.8 / 3.1（EXP-V1-03-E）。

## 三、被否定 / 弱化的假设

1. ~~"谱质心本身是问题特征"~~ → 弱化：删掉谱质心有效，但删掉 RMS 同样有效，
   更可能是两者近共线（r ≈ −0.95）造成的病态，而不是单个特征"坏"。
2. ~~"正常文件之间的相关性反转是误报原因"~~ → **未成立（Evidence Level C）**：
   四个关键相关性的 bootstrap 95% 置信区间全部重叠，无法排除小样本随机波动。
3. ~~"调阈值可以解决误报"~~ → 弱化：在当前扫描范围内无效（EXP-V1-01），
   扩展范围的复核保留为 EXP-V1-06。

## 四、当前最可信机制（Evidence Level B）

> 观察到的误报与"训练正常数据和测试正常数据之间的多变量依赖结构变化"这一解释一致，
> 而单变量均值/尺度漂移不足以解释；但因样本量小，尚不能用该解释定性。

当前证据更支持的具体机制是：**协方差矩阵病态**——RMS 与谱质心高度相关（近共线），
加上训练样本仅 22 个，使 Σ⁻¹ 对微小偏差极度放大，导致正常窗口距离虚高。

该机制与两类证据一致（条件数 10⁹ 量级；删除共线特征之一即大幅减少误报），
但仍需 EXP-V1-04 的受控实验确认，属 Level B。

## 五、当前最大风险

1. 统计功效不足：训练 22 个窗口、测试正常仅 11 个窗口、只有 1 个正常测试文件。
2. 单数据集、单传感器、单划分，结论可能只是"这个划分的偶然现象"。
3. 容易过度解读相关关系（条件数 ↔ 误报）为因果关系。

审稿人最可能问：**样本这么少，你的机制结论有多稳？** —— 这必须由 EXP-V1-04/07 回答。

## 六、下一实验与理由

### EXP-V1-04：Well-conditioned Feature Set Control

**为什么做**：EXP-V1-03 提出"病态协方差 → 误报"这一机制，但只有相关性证据。
需要一个只改变"特征条件数"的受控实验来检验它的可验证预测。

**可验证预测**：条件数更低（更良态）的特征组合，其马氏距离分布更稳定、误报更少。

**控制变量**：数据集、train/test 划分、窗口参数、检测方法（马氏距离）、
协方差估计方式、分位数 0.99、阈值推导方式、评价协议全部保持一致。

**对比特征集**：RMS / RMS+Kurtosis / RMS+Crest / RMS+Centroid /
RMS+Kurtosis+Crest / All features。

**记录**：condition number、threshold、FP、TN、FPR、F1、Recall、距离分布。

**判据**：条件数与误报之间是否呈一致关系（不能只凭相关系数下因果结论）。

## 七、V1-04 之后的动态分叉

```text
EXP-V1-04 结果
   ├── 支持"病态协方差"假说
   │      → EXP-V1-05 Shrinkage Covariance（只替换协方差估计，检验能否修复）
   └── 不支持
          → 弱化/放弃该解释，重新检查 threshold、距离分布、特征几何等机制
             （不得为了保住故事而强行解释）
```

## 十二、论文故事版本（当前，会随证据调整）

> 简单、可解释的异常检测器在严格评估、小样本与高相关特征条件下会出现系统性的误报；
> 本项目通过多层评价、消融实验与受控条件数实验研究其失效机制，并检验更稳健的检测策略。

候选贡献（暂定，需证据支持）：

1. 面向低成本监测的多层、泄漏安全评价协议（window / file / leave-one-file-out）。
2. 特征相关性与条件数对误报影响的受控实验证据。
3. 小样本条件下区分"真实机制"与"随机波动"的统计规范（bootstrap 置信区间）。
4. 基于稳健协方差的修复方案及其受控验证。
5. 机制在跨数据集场景下的一致性验证。
