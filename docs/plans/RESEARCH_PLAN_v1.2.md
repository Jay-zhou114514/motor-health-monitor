## 二、已确认事实（Evidence Level A）

沿用 v1.1，并新增 EXP-V1-04 的结果：

1. 故障检测本身容易：所有特征组合召回率 = 1.000（EXP-V1-02）。
2. 方法 A（RMS 3σ）在 k = 2.5~4 稳定（EXP-V1-01）。
3. 方法 B 对阈值不敏感（q = 0.90~0.999 指标不变）（EXP-V1-01）。
4. 特征越多误报越多：RMS only = 1；+峭度/峰均比 = 2；+谱质心 = 8；四特征 = 9（EXP-V1-02）。
5. 误报分散于整段记录（9/11），距离贡献主要来自 RMS 与谱质心（EXP-V1-03）。
6. 删除 RMS 或谱质心后误报 9 → 2~3（EXP-V1-03）。
7. 含 RMS + 谱质心的特征集条件数达 10⁹ 量级，其距离膨胀比 > 1（1.35~1.50），
   其余 7 个特征集膨胀比 < 0.8（EXP-V1-04）。

## 三、被否定 / 弱化的假设

1. ~~"条件数高是误报的主机制"~~ → **不能作为主机制**：
   crest + centroid（4.2×10⁵）与 kurtosis + centroid（2.0×10⁸）同样病态却无严重误报。
2. ~~"条件数高使阈值估计不稳定"~~ → **不支持**（Spearman ρ = 0.264，p = 0.43）。
3. ~~"误报出现的条件是近共线 + 方向一致"~~ → **撤回该措辞**，降级为假说：
   该"方向一致性"来自 V1-04 的事后观察，且只有 1 个正常测试文件、11 个窗口。

## 四、当前最可信机制（Evidence Level B）

> 当前结果提示，误报可能与 RMS–谱质心近共线结构及其对应低方差方向
> 与正常文件间分布差异的对齐有关。

说明：这是**合理假说、尚未证实**；经验协方差在 n = 22 下的估计误差
也是合理但尚未单独验证的因素。

## 五、当前最大科研风险

1. 统计功效不足：训练 22 个正常窗口、测试正常 11 个窗口、仅 1 个正常测试文件。
2. "方向一致性"是事后观察，存在事后构造机制的风险。
3. 若 V1-05 不支持该机制，必须推翻并重新定位，而不是继续修补故事。

## 六、下一实验：EXP-V1-05 Covariance Geometry & Regularization（锁定）

**定位：机制验证优先、修复验证并行。** 目标不是提高 F1，而是搞清楚
这个马氏距离检测器**为什么错**，以及该原因**能否被修复**。

### 只做三个对照组（不再扩展特征集）

| 组 | 角色 |
| --- | --- |
| RMS + kurtosis | 正常对照（良态） |
| RMS + centroid | 问题组（病态 + 距离膨胀） |
| crest + centroid | 高条件数但无严重误报的**反例组** |

第三组最关键：它能回答"是不是病态本身导致问题"。

### ① B：方向归因（必须做）

回答：**距离膨胀到底是不是来自低方差 / 最小特征值方向？**

检查内容：

- 协方差矩阵的特征值谱
- 最小特征值对应的特征向量
- 正常测试样本在该方向上的投影
- 马氏距离的逐特征/逐方向贡献分解
- RMS + centroid 与其他特征组的对比

### ② A：协方差正则化（并行）

回答：**若问题确实来自协方差几何，修正协方差后误报与距离膨胀是否下降？**

至少比较：经验协方差 vs 收缩协方差（如 Ledoit–Wolf）。

**硬性规则：任何 λ / 超参数只能利用训练或验证数据确定，测试集完全不能参与。**

### 判定标准

- 支持：低方差方向投影/贡献能解释膨胀，且正则化使膨胀比与误报下降。
- 不支持：膨胀无法归因到该方向，或正则化无效 → 推翻机制，重新定位。

### 风险

1. 只有 1 个正常测试文件，任何"方向一致"的结论都只能作为线索。
2. 收缩强度若在测试集上选择即为数据泄漏，必须避免。
3. 三个对照组仍然共享同一数据划分，不能外推为普遍规律。

## 九、论文故事版本（本版）

> 我们不寻找一个把 F1 做得更高的方法；我们研究一个简单、可解释的检测器
> 在严格评估与小样本条件下为什么会失败，并检验该原因能否被修复。
