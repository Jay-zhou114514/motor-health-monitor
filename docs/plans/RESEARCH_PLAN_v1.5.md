## 二、已确认事实

1. **判别力不是瓶颈**：MFPT 上四种检测器 AUROC 全为 1.000（EXP-V1-08）；
   多特征组合下召回率恒为 1.000（EXP-V1-02）。
2. **差异集中在误报**：IMS 三批次留出健康记录的误报率——
   A 3σ RMS **2.4% / 2.4% / 2.4%**；D iForest 3.6–4.8%；B 马氏 4.8–16.7%；
   **C One-Class SVM 27.4–50.0%**（EXP-V1-08）。
3. **单类方法对训练样本量敏感**：每折仅 11 个训练窗口；RBF 单类 SVM 不稳定
   → 方法复杂度不能替代样本量（EXP-V1-08）。
4. **单数据集结论不可外推**：EXP-V1-05/06 观察到的"距离膨胀导致大量误报"
   在三个独立批次上未复现（EXP-V1-07，P1 不成立）。
5. **功效必须报告**：H1 需约 29 个正常文件、H2 约 10 个；
   当前 3 个文件时功效仅 0.087 / 0.180（`POWER_ANALYSIS_V1.4.md`）。
6. **文献定位**：泄漏与基准已有人做（Vieira 2026；Knap 2026）；
   但在其全文中 `unsupervised` / `one-class` / `anomaly detection` /
   `statistical power` / `sample size` 均 **0 命中**（`EVIDENCE_MATRIX.md`）。

## 三、被否定 / 弱化的表述

1. ~~"几何失效 + 收缩修复"是普遍机制~~ → 未复现（EXP-V1-07）。
2. ~~"现代单类方法更可靠"~~ → 在本场景误报更差（EXP-V1-08）。
3. ~~"泄漏安全划分是我们的创新点"~~ → 已被先行工作占据。

## 四、当前最可信结论（Level B）

> 在**只有健康数据可训练**的泄漏安全协议下，简单统计检测器在**记录级误报控制**上
> 不逊于现代单类基线；**评价协议（评价单元独立性 + 统计功效）比模型复杂度更能决定结论可靠性**。

## 五、当前最大风险

1. 每折训练窗口少（11 个），单类方法表现可能被超参设置放大；
2. 独立单元只有 3 个 IMS 批次 + 1 个 MFPT 试验台 → 不做显著性声称；
3. MFPT 判别任务过易（AUROC=1.000），不能代表更难场景；
4. 不含深度基线；不含真实数据。

## 六、下一实验：EXP-V1-09（训练内超参协议）

**可检验预测**：若在**训练/验证数据内**（不得使用测试集）为 One-Class SVM
与 Isolation Forest 选择超参，能否把其在 IMS 上的误报率降到与 3σ RMS 相当（≤5%）？

- 超参网格：OC-SVM 的 `nu`（如 0.001–0.1）与 `gamma`；iForest 的 `n_estimators` 与 `max_samples`；
- 选择准则：只用训练文件内部留一（leave-one-file-out within training）选择；
- 判据：支持 = 至少一种现代方法在 3 个 IMS 批次上误报 ≤ 5%；不支持 = 均 > 5%；
- 记录：误报率、AUROC、选择到的超参、耗时。

## 七、暂缓项

- 深度基线（1D-CNN）——除非审稿人要求；
- Paderborn（6 个独立物理轴承）：**现在有了正当用途**（做"简单 vs 现代"的独立单元强对比），
  但优先级低于 EXP-V1-09；
- 真实自采数据。
