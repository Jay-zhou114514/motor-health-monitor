## 二、已确认事实（本数据集内的受控实验结果）

1. 问题组（RMS + centroid）的 Mahalanobis 距离高度集中于最小特征值方向：
   标准化方向上占比 0.937（对照组 0.888，反例组 0.305）。
2. 当前划分下，训练集解析式 LW 收缩（δ = 0.220，未使用测试集）
   使问题组 FP 9 → 1、膨胀比 1.576 → 0.311、F1 0.873 → 0.984。
3. 反例组（crest + centroid，条件数 4.24 × 10⁵）在正则化前后 FP 均为 1。
4. 对照组（RMS + kurtosis）在 LW 下取到 δ = 1.000 的边界解，FP 2 → 3。

**以上均为"在当前划分下的结果"，不是泛化性能估计。**

## 三、被否定 / 弱化的表述

1. ~~"对齐（低方差方向）是误报的充分条件"~~ → 已弱化：对照组同样对齐（0.888）却几乎不误报。
2. ~~"真正区分两组的是标准化投影幅度"~~ → 降级为**后验线索**：
   该指标尚未被预先定义、尚未在独立数据上验证、尚未证明能预测 FP。
3. ~~"LW 是检测任务意义上的最佳正则化方案"~~ → 未成立：
   LW 解析式优化的是协方差估计，不是"正常样本距离是否膨胀"这一检测目标。
4. ~~"LW 在良态数据上失效"~~ → 修正为：在当前样本规模与特征组合下，
   LW 解析估计在该对照组产生了 δ=1 的边界解，提示其收缩强度估计
   可能具有较强的几何 / 样本依赖性。

## 四、当前工作假说（Evidence Level B，保留但不宣布成立）

```text
病态协方差
      ↓
最小特征值方向
      ↓
标准化偏离增大
      ↓
Mahalanobis 距离膨胀
      ↓
正常样本误报增加
      ↓
shrinkage 后膨胀下降
```

该链条目前"有支持的机制假说"，而不是"已验证机制"。

## 五、当前最大风险

1. **11 个正常测试窗口（同一文件）**：FP 分辨率 9.1%，9 → 1 不能视为稳定泛化估计。
2. 问题组与对照组共享同一 train/test split，无法区分"普遍几何问题"与
   "baseline_1+2 → baseline_3 这一特定迁移关系的现象"。
3. H1 的关键区分量（标准化投影幅度）是**事后发现**的 → post-hoc 风险。
4. LW δ=1.000 的边界解提示收缩强度估计不稳定。
5. 缺乏与测试无关、且经过验证的 δ 选择准则。

## 六、下一实验：EXP-V1-06（两部分）

### V1.06-A：验证 H1（先预注册，再验证）

**不再寻找新指标**：把 EXP-V1-05 已观察到的
「标准化投影幅度 = |样本在最小特征值方向的投影| / √λ_min」
**提前冻结定义**，然后在新数据 / 新划分上验证：

> 低方差方向上的标准化偏离，是否能在新的正常文件或新的划分中复现？

可行的实现（现有数据即可做）：

- 三折 leave-one-normal-file-out 轮换：
  (baseline_1 + baseline_2) → baseline_3；(baseline_1 + baseline_3) → baseline_2；
  (baseline_2 + baseline_3) → baseline_1。
- 若后续能获得更多公开正常数据，再作为独立验证集加入。

判据（需在跑之前写定）：三折中问题组的标准化投影幅度是否稳定高于对照组，
且该幅度是否与 inflation / FP 同向变化。

### V1.06-B：验证 H2 与 δ 选择

比较**预先定义的** training-only 选择准则：

- δ = 0（经验协方差）
- LOO likelihood（窗口级留一）
- LW 解析式
- 其他预定义准则（例如以留出正常文件的标准化投影幅度为目标的准则）

核心问题：

> 不同 training-only 选择准则，能否稳定选出合理的 δ？

规则：**测试集只在最后打开一次**；任何准则在选定 δ 之前不得接触测试数据。

## 七、可以现在做 / 不能声称什么

可以现在做：

- 定义准则、训练集内部 CV、比较 δ 选择方法、敏感性分析、

- 最优 δ；普适的 δ 选择方法；跨设备 / 跨工况泛化；
  普遍解决 Mahalanobis 误报膨胀。

## 八、判定升级 / 降级规则

- **升级到 A**：V1.06-A 复现"低方差方向 + 标准化偏离 → inflation"，
