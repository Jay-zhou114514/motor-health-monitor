依据：EXP-V2-01（`experiments/EXP-V2-01-cross-dataset-scaling.md`）+ 预注册修订 1/2/3。

| 处理 | 内容 |
| --- | --- |
| **因结果而确立** | **在仅健康数据的轴承异常检测中，名义样本量增长不等于有效信息增长**：同一 20 条记录重采样到 n=96，SD 停在 18 pp；96 条真实不同记录时 SD 降到 0 |
| **因结果而更正** | EXP-V1-11 的"饱和"被解释为**固定总体 + 重采样**的产物；其记录与本文档的相关表述已加限定语 |

| 判据实现缺陷 | P1/P4 因退化格（n_eff = ∞）失败；属**实现缺陷**而非数据结论，已在记录中如实标注并列为 Level C |
