## 2. 问题 1（表述性，必须在论文中修正）

方差分解给出的"划分 5.20 pp / 种子 4.39 pp"是在**配置固定**（iForest 200/0.5）下测的，
而主分析的 4.13 pp 是**包含配置选择**的总效应。**两者不是同一个总量的组成部分。**

若并排写而不加说明，属于表述不实。

正确的写法：

> At the modal configuration, split composition contributed SD 5.20 pp and the random
> seed 4.39 pp. In the full pipeline, where the configuration is re-selected in each
> resample, the total spread was 4.13 pp — i.e. configuration selection did not add
> spread beyond the fixed-configuration setting.

（附带一个有价值的观察：**总效应并不大于固定配置下的划分效应**。）

## 3. 问题 2（方法学，必须在写作前解决）

**V2-01 / V2-02 存在轴承级泄漏。**

- 固定测试集 = 每个轴承的 17–20 号记录；训练池 = 同批轴承的 1–16 号记录；
- 因此**同一物理轴承同时出现在训练与测试中**（已用 `paderborn_data` 复核：两边轴承集合完全重合，交集 = K001–K006）；
- 这违反本项目 `FROZEN_PROTOCOL.md` 自己的规则："独立单元是试验批次或物理轴承"；
- 这也正是 Vieira et al. (2026, MSSP) 指出并纠正的问题（bearing-wise 划分）。

影响评估：

1. **S1 vs S2 的对比方向不受影响**——两臂使用完全相同的测试集，比较是内部的、同一口径的；
2. **但绝对误报率水平不是泄漏安全的**，会被同一轴承"见过"而过低估计；
3. 训练池内各轴承的 rms 均值差异明显（K001 0.403 vs K004 0.171），
   说明持出整颗轴承时模型会明显更差 → **修正后数字可能显著变化**；
4. 读过 ref [15] 的审稿人会立刻指出这一点。

**结论：先修正，再写 Discussion。** 否则 Discussion 与 Results 都要重写。
