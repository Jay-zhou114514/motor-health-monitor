# 实验后置清单（Experiment Aftercare Checklist）

- 版本：v1.0
- 日期：2026-09-19
- 状态：**强制**。任何实验从"跑完"到"进入下一实验"必须走完本清单。
- 教训来源：2026-09-17~19 期间累计 8 次"假设被验证推翻"
  （通道识别 ×2、传闻式排除、分隔符、N 计数口径、判定实现缺陷 ×2、判定维度被覆盖 ×1）。

## 强制顺序（不可跳步、不可调序）

```text
实验完成
  ↓
① L1 不变量检查      （秒级）
② L2 独立复算        （分钟级；另一条代码路径）
③ L3 确定性重跑      （小时级；SHA-256 逐字节比对）
  ↓
④ 结果审查           （结果是否真的支持预注册判据？逐条对照）
⑤ 假说判定           （支持 / 部分支持 / 不支持 / 无法判定）
⑥ 风险审查           （混杂、替代解释、措辞是否过强）
⑦ 更新研究路线       （下一实验是什么？为什么是它？）
⑧ 发布新版本         （计划版本 / 注册表 / CHANGELOG / 门控）
  ↓
下一实验
```

**未通过 ①–③ 的实验不得进入 ④。**

## 每一步的具体要求

| 步 | 要求 | 产物 |
| --- | --- | --- |
| ① | 取值域、缺失值、训练量一致性、折数完整、**退化格显式标记**、分组键不丢失 | 控制台输出 |
| ② | 用**另一条代码路径**重算头条数字；**特征层抽检**（直接重读源文件）；逐项比对 | 控制台输出 |
| ③ | 重跑并计算 SHA-256，与归档版本比对 | `*-hashes.txt` |
| ④ | 逐条列出预注册判据 vs 实际值，**不得只看结论** | 实验记录 §判定 |
| ⑤ | 四档之一，附证据等级 A–D；退化格导致的失败必须标注为**判定实现缺陷**而非数据结论 | 实验记录 §判定 |
| ⑥ | 至少写出：混杂、替代解释、措辞过强处、**上一版回答里被推翻的话** | 实验记录 §限制 |
| ⑦ | 写出下一实验及其**优先级理由**（为什么是它而不是别的） | 计划 §下一实验 |
| ⑧ | 计划文件（若结构变）/ 实验注册表 / CHANGELOG / 门控状态 | 四份文档同步 |

## 五件套（每次都不可少）

`实验记录 .md`、`脚本 .py`、`结果 CSV`、`运行日志 .txt`、`图 .png`（+ 哈希文件）

## 反模式清单（已实际发生过，禁止再犯）

1. **静默丢弃退化格**（SD=0 / n_eff=∞）→ 必须标记并单独报告；
2. **用数据集全局最大 k 去汇总各规则** → 必须按每条规则**自身**的 k_max；
3. **汇总时覆盖分组键**（如把 `rule` 覆盖成 `tag`）→ 汇总表必须保留全部实验条件列；
4. **用 Python 内建 `hash()` 派生随机种子** → 必须用 `zlib.crc32` 等跨进程确定值；
5. **凭"公开资料说"处理数据**（通道、排除规则、分隔符）→ 必须读原始文件/官方文档验证；
6. **按"所有文件"计数**（含温度等非目标通道）→ 必须按目标文件模式计数；
7. **判定规则未考虑退化/饱和** → 预注册时必须显式写明退化情形如何处理；
8. **只跑一个模型/一个参数就下跨数据集结论** → 要么补对照，要么把结论限定到该设置；
9. **在目标文件尚未被重写时比对哈希** → 会出现"旧文件与新基准一致"的**假通过**。
   守卫条件：比对前必须确认输出文件的 `LastWriteTime` **晚于本次重跑的启动时间**，
   否则一律判为"尚未重写"。
10. **比较两个"效应大小"时使用了不同的自变量范围** → 会产生无意义的比值。
    EXP-V2-05 的 Y3 初版即犯此错：用 k=1→12 的跨工况比值去比 k=1→4 的工况内比值。
   **规则：任何效应比较必须使用相同的自变量范围。**
11. **在反模式清单里写下规则、却在预注册时没有实现它** → 规则形同不存在。
   EXP-V2-06 的马氏距离判据即因此被**饱和基线**污染（k=1 误报 100% → SD=0）。
   **规则：预注册必须包含"本条如何落实"的实现说明，而不只是列出风险名称。**
12. **把"计数列"当"比率列"检查、或对已舍入的存储值用过严容差** →
   EXP-V1-05~1-10 的补验证中，`fp`（误报**个数**）被误判为越界，
   汇总表的 4 位小数舍入被误判为不一致（差 4.76e-05）。
   **规则：验证脚本必须区分计数与比率；容差必须依据存储精度设定。**
13. **L3 逐字节比对包含了非确定性的元数据列**（计时 `seconds`、内存、时间戳）→ 必然"不一致"。
   EXP-V1-10 的 L3 首次失败即由此造成：350 行的**全部科学列 0 处不同**，仅 `seconds` 不同。
   **规则：L3 比对必须排除非确定性列，或对这些列单独声明"不参与比对"。**
14. **凭印象著录引用（作者、标题、年份）** → 参考文献第 12 项原写 "Baumann, D., & Baumann, K. (2014)"，
   Crossref 实为 **Krstajic, D., Buturovic, L. J., Leahy, D. E., & Thomas, S.**（作者与标题均错）。
   **规则：每一条引用在写入正文前必须经 Crossref/arXiv 逐条核对；无 DOI 的数据集引用不得自造著录。**
