# 冻结协议（Frozen Protocol）

- 版本：v1.0
- 日期：2026-09-17
- 状态：**冻结**。修改本文件必须另开修订记录，说明修改原因与生效时间。
- 作用：满足 `docs/plans/V1_TO_V2_GATE.md` 的判据 **G2**。

任何实验、分析、图、论文表格都必须与本文件一致；不一致必须在对应实验记录中显式声明偏差。

## 2. 特征

四个可解释的时域 / 频域特征，自 V1-02 起冻结：

```text
rms, crest_factor, kurtosis, centroid_hz
```

不再增加特征。若实验需要特征子集（如 V1-05 的三组对照），必须在预注册中写明。

## 4. 阈值与选择

1. 阈值 = **训练集分数**的 0.99 分位数（`QUANTILE = 0.99`）；
2. 所有超参数、协方差、阈值、收缩强度 **只能由训练数据确定**；
3. 测试集只用于最终评估，**任何环节不得查看测试集**；
4. 选择准则 = 验证集误报率最小；并列时按冻结网格顺序（更保守者优先，确定性规则）；
5. 评价必须报告分记录级（file-level）结果，不得只报窗口级。

## 5. 冻结网格

```text
One-Class SVM: nu ∈ {0.001, 0.005, 0.01, 0.05, 0.1} × gamma ∈ {scale, 0.1, 1.0, 10.0}
Isolation Forest: n_estimators ∈ {200, 100} × max_samples ∈ {0.5, 0.8, 1.0}
```

网格顺序即并列时的优先顺序（iForest：先更多树，再更保守的 `max_samples`）。

## 6. 报告格式（五维）

| 维度 | 指标 |
| --- | --- |
| Performance | FP rate / Recall / F1（分记录级） |
| Selection stability | 模态配置占比、不同配置个数、归一化熵 |
| Selection cost | 候选配置数、拟合次数、耗时 |
| Selection sensitivity | 验证划分微扰后最终配置是否改变 |
| Generalization | 选出的配置换批次 / 换体系是否仍有效 |

## 7. 证据等级

| 等级 | 含义 | 允许出现的位置 |
| --- | --- | --- |
| A | 多独立单元 + 预注册 + 完整产物 | Abstract / Conclusion |
| B | 单一体系或单一划分，效应方向清楚 | Results（须标注限制） |
| C | 单点观察 / 后验发现 | 只能写为线索 |
| D | 功效不足或与噪声基准不可区分 | 只能写为 limitation |

**C / D 级证据不得进入 Abstract 与 Conclusion。**

## 8. 三层报告

每条结论必须能拆成：**Observation（事实）→ Interpretation（解释）→ Limitation（不能证明什么）**。
Interpretation 不得写成 Observation。
