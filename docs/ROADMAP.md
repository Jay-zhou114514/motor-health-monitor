# Motor Health Monitor · 项目路线图

> v0 = 模拟数据入门原型（已完成）；v1 = 真实公开数据 + 异常检测（已完成）；v2/v3 见下。
> 差异化：这个题目很多人做过，本项目的竞争力来自问题定义、成本决策、跨数据验证与真实数据。

## 差异化策略

1. 讲清楚为谁解决什么问题（小型工厂低成本监测、减少意外停机）。
2. 把报警阈值与维护成本挂钩，而不是随意取 3 倍标准差。
3. 用跨数据集验证证明方法有泛化能力，不是"只认一套数据"。
4. 保留失败与迭代记录，展示诚实、可验证的成长。
5. 有条件后用低成本硬件采集自己的数据。

## v1 结果（窗口级）

| 指标 | 方法 A（3σ） | 方法 B（马氏距离） |
| --- | ---: | ---: |
| 准确率 | 1.000 | 0.786 |
| 精确率 | 1.000 | 0.775 |
| 召回率 | 1.000 | 1.000 |
| F1 | 1.000 | 0.873 |

要点：RMS 单特征在这份数据上最可靠；马氏距离召回率同为 100%，但误报更多，
说明特征增多不一定更好，阈值需要结合维护成本来选择。

## v2 / v3 方向

- v2.1 跨数据集验证：MFPT 训练正常状态 → NASA IMS 测试泛化能力。
- v2.2 NASA IMS run-to-failure 退化趋势分析。
- v2.3 故障类型分类（内圈/外圈/滚动体）。
- v2.4 包络谱 / 短时傅里叶等时频方法。
- v3：ESP32 + 低成本传感器搭建验证台并采集自己的数据。
