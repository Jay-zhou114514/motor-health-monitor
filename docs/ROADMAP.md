# Motor Health Monitor · 项目路线图

> 版本说明：v0 = 模拟数据入门原型（已完成）；v1 = 真实公开数据 + 异常检测（当前目标）；v2/v3 见下。
> 差异化：这个题目很多人做过，本项目的竞争力来自问题定义、成本决策、跨数据验证与真实数据。

## 差异化策略

1. 讲清楚为谁解决什么问题（小型工厂低成本监测、减少意外停机）。
2. 把报警阈值与维护成本挂钩，而不是随意取 3 倍标准差。
3. 用跨数据集验证证明方法有泛化能力，不是"只认一套数据"。
4. 保留失败与迭代记录，展示诚实、可验证的成长。
5. 有条件后用低成本硬件采集自己的数据。

## v1 完成标准

1. 接入真实滚动轴承振动数据（MathWorks 数据，含正常/外圈故障/内圈故障）。
2. 按窗口提取时域与频域特征。
3. 对比两种异常检测方法：统计阈值基线 vs 马氏距离法。
4. 在测试集上输出准确率/召回率/F1，并给出局限性。
5. 加入维护成本视角：解释误报与漏报代价，说明阈值选择依据。
6. 自动生成实验报告与图表。
7. 文档齐全，推送到 GitHub 新仓库 `motor-health-monitor`。

## 分步任务

- [x] v0：模拟信号生成、画图、简单阈值报告
- [x] v1.0 流水线骨架：模块划分、语法与算法自测
- [ ] v1.1 数据加载（读取 .mat，整理成表）
- [ ] v1.2 特征提取（RMS、峰值、峭度、谱质心等）
- [ ] v1.3 方法 A：正常数据统计阈值
- [ ] v1.4 方法 B：马氏距离轻量检测
- [ ] v1.5 评估：混淆矩阵与指标
- [ ] v1.6 成本视角：误报/漏报代价分析与阈值讨论
- [ ] v1.7 图表与实验报告输出
- [ ] v1.8 README（用户故事 + 数据许可 + 局限）与上传 GitHub

## v2 / v3 方向

- v2.1 跨数据集验证：MFPT 训练正常状态 → NASA IMS 测试泛化能力。
- v2.2 NASA IMS run-to-failure 退化趋势分析。
- v2.3 故障类型分类（内圈/外圈/滚动体）。
- v2.4 包络谱 / 短时傅里叶等时频方法。
- v3：ESP32 + 低成本传感器搭建验证台并采集自己的数据。
