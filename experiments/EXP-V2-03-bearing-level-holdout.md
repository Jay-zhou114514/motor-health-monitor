## 1. 设计

| Regime | 训练 | 测试 | 折数 |
| --- | --- | --- | ---: |
| **R1 within-bearing**（旧口径） | 各轴承记录 1–16（96 条） | 各轴承记录 17–20（24 条） | 1 |
| **R2 bearing-level holdout**（新口径） | 其余 5 颗轴承全部记录（100 条） | 留出轴承的 20 条记录 | 6 |

臂：S1 重采样（固定 20 条子集有放回抽 n）、S2 真实新增（无放回抽 n 条不同记录）、

## 3. 预注册判据判定

| 判据 | 实际 | 判定 |
| --- | --- | --- |
| P1（R2 中 SD96(S2) < SD96(S1)） | **2/6** | **不成立** |
| P4（R2 中 S2 的 SD 随 n 下降） | 5/6 | 成立 |
| P5（S3 的 SD 随轴承数下降） | **5/6** | 成立 |
| P6（SD(k=5) < SD(k=1)） | **5/6** | 成立 |
| P7（SD(k=1)/SD(k=5)） | 4.62 / 3.79 / 5.71 / 8.98 / 0.79 / — | 中位数约 **4.6 倍** |

**P1 失败的原因必须如实记录**：在 R2 下，S1 往往**饱和在 100% 误报**，
"每一折都是 100%" 使 SD = 0，于是 S1 看起来比 S2"更稳"。
这是**退化稳定性**，不是方法优越。**判据设计未考虑饱和**（与 EXP-V1-11 的 P3 同类型缺陷）。

## 4. Observation

1. **within-bearing 评价把误报率压低了一个数量级以上**：n=96 时 R1 = 0.00%，R2 = 40.63%；
   个别折（K002/K004/K005）持出轴承的误报率达 69–97%。
2. **S3 显示独立单元数确实降低估计不确定性**：固定 20 条记录，
   从 1 颗轴承增到 5 颗，SD 中位数下降约 **4.6 倍**（5/6 折成立）。
3. R1 下 S2 的 SD 随 n 单调降到 0（P4 = 5/6），与 EXP-V2-01 一致。
4. 在 R2 下，**同一方法在不同留出轴承上的表现差异极大**（S2 从 0.00% 到 97.10%），
   说明**轴承之间的差异是主导因素**。

## 5. Interpretation

1. **核心结论成立且更强**：
   > 在仅用健康数据的轴承异常检测中，**报告的误报率主要由评价口径决定**——
   > 是否留出**整颗物理轴承**，可以让同一个方法从"0% 误报"变成"40% 误报"。
2. **"独立单元要求"现在有实验支撑**（P5/P6 成立）：在**样本量固定**时，
   增加独立轴承数显著降低估计不确定性。这正是会议稿此前无法主张、而 S3 臂补上的那条。
3. **P1 的失败不推翻主结论，但改变了它的形式**：主对比不再是"S2 的 SD 小于 S1"，
   而是"**S1 在持出轴承上饱和，因此其低方差是退化的**"。
   论文必须把"饱和"作为一种失效模式单独写出。
4. **与既有工作的关系（必须再次声明）**：
   "记录级划分抬高指标"已是 Vieira et al. (2026, MSSP) 的既有工作。
   本实验的**增量**是：
   （a）把口径差异量化到**误报率**这一终点上（他们的终点是分类性能）；
   （b）**同一实验内**同时给出"单元数固定、只改独立单元数"的对照（S3），
        这一条在既有工作中未出现；
   （c）饱和现象（100% 误报导致 SD=0）作为评价陷阱被显式识别。
5. **对论文叙事的影响**：R1 应作为 **sanity check / 对照**，
   主线改为"**独立单元要求 + 口径决定结论**"；S1 的角色进一步弱化。

## 6. Limitation

1. 仅 Paderborn 单一工况（`N15_M07_F10`）、6 颗物理轴承；其余 3 工况未重跑；
2. 单一检测器（iForest 200/0.5）与单一分位（q = 0.99）；
3. 测试集分辨率：R2 每折只有 **1 个独立测试单元**（20 条记录来自同一颗轴承），
   因此"折内 SD"与"跨折差异"是两个不同的量，本记录已分开报告；
4. **P1 的判定设计有缺陷**（未处理饱和），如实记录，修正后属事后分析；
5. `n=96` 时 S1 出现 SD = 0 的退化格，不能解读为"稳定"。
