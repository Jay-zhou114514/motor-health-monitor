## 1. 实验契约

| 项目 | 内容 |
| --- | --- |
| Positioning | 机制验证优先、修复验证并行；目标不是提高 F1 |
| H1（方向归因） | 问题组的距离膨胀可归因到协方差的最小特征值方向 |
| H2（正则化） | 若 H1 成立，收缩协方差应同时降低距离膨胀与误报 |
| Groups | RMS + kurtosis（对照）、RMS + centroid（问题组）、crest + centroid（反例组） |
| Control | 数据、划分、窗口、分位数 0.99、阈值推导、评价协议完全一致 |
| Rule | 协方差与所有超参数只由训练数据确定；测试只用于评价 |
| Output | 方向归因表、正则化对比表、逐窗口统计、图 |

## 3. Observation（观察到什么）

1. 问题组的距离膨胀确实集中在最小特征值方向：93.7% 的 D² 来自该方向，
   标准化投影 2.93（> 1，即单这一方向就超过阈值）。
2. **但对照组也表现出方向对齐**（占比 0.888、标准化投影 1.61），
   说明"对齐"本身不是问题组独有的性质。
3. 反例组（条件数 4.24 × 10⁵，同样病态）没有膨胀：占比仅 0.305、标准化投影 0.75。
4. 正则化只在该问题组"救得回来"：Ledoit–Wolf δ = 0.220（由训练数据解析式确定）
   使条件数 3.55 × 10⁹ → 8.08、FP 9 → 1、膨胀比 1.576 → 0.311、F1 0.873 → 0.984。
5. 对照组在 LW 下 δ = 1.000（协方差被完全丢弃），FP 2 → 3，略变差。
6. **LOO 似然准则在两个病态组都选择 δ = 0（不收缩）**，
   即"只用训练数据的似然"无法发现这个问题；而 LW 解析式选了 δ = 0.220 且有效。

## 4. Interpretation（初步理解，待审查）

1. **H1（方向归因）：部分支持。**
   膨胀确实由最小特征值方向承载（0.937），但对照组也显示对齐（0.888），
   因此"对齐"不是充分条件。区分两组的是**标准化投影的幅度**（2.93 vs 1.61）——
   该幅度随 λ_min 变小而放大，是"低方差方向 + 文件间差异"共同作用的结果。
2. **H2（正则化）：部分支持。**
   训练集解析式 LW 收缩把问题组的 FP 9 → 1、膨胀比 1.58 → 0.31，反例组不受影响；
   对照组反而略变差（2 → 3，考虑到只有 11 个正常窗口，属噪声范围）。
3. **本实验暴露的新问题（比结论更重要）**：
   如何在不使用测试数据的前提下选择收缩强度？
   LOO 似然选 δ = 0（无效），LW 解析式选 δ = 0.220（有效）——
   说明"选择准则"本身是尚未解决的问题，不能默认任意收缩都可行。
4. 证据等级：H1 = Level B；H2 = Level B（有效果，但选择准则不可靠）。

## 5. Limitation（风险审查要点）

1. 只有 1 个正常测试文件（11 个窗口），FP 分辨率只有 1/11。
2. 对照组在 LW 下 δ = 1.000 属退化情形（协方差被完全丢弃），
   说明 LW 解析式在良态数据上未必合适。
3. 三个特征组共享同一数据划分，无法排除划分特异性。
4. "标准化投影幅度"是事后归纳的描述，尚未经过预先定义假设的检验。
5. 收缩强度选择缺乏与测试无关的可靠准则——这是当前最关键的遗留问题。
