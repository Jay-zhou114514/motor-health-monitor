# EXP-V2-06 预注册：在 run-to-failure 数据集上补齐第二个/第三个检测器

- 日期：2026-09-19
- 状态：**在运行之前冻结并提交**
- 触发：EXP-V2-05 已把第二层结论收紧为**主张 A**（工况固定下单元效应成立）。
  此时"只有一个检测器（iForest 200/0.5）"成为剩余最大短板（风险登记 R2）。

## 1. 研究问题

> EXP-V2-05 的结论（工况固定下，独立训练轴承数降低报告误报率的不确定性）
> **是否在其它检测器上同样成立**？

## 2. 设计

**完全复用 EXP-V2-05 的采样设计**（同工况分层、同 budget=20、同折、同 k 范围、同重复次数），
只替换检测器：

| 代号 | 检测器 | 阈值 |
| --- | --- | --- |
| **A** | 3σ RMS（只用 `rms` 特征） | 训练分数的 0.99 分位（与冻结协议一致） |
| **B** | 马氏距离（4 特征、经验协方差 + 1e-12 对角正则） | 训练分数的 0.99 分位 |
| D | Isolation Forest(200, 0.5) | 已有（EXP-V2-05） |

**新增的判据效力要求（本次自审教训）**：
预注册同时记录**每次抽样的工况构成**，用于事后核对"对比臂是否可比"。
上一轮（V2-05）的 Y3 就是因为比较对象本身接近单工况而证据不足，本次不允许重犯。

## 3. 判据

| 编号 | 判据 |
| --- | --- |
| **Z1** | 对 A 与 B 各自：SD 随 k 下降的（数据集 × 工况）单元占比 ≥ 80% |
| **Z2** | 对 A 与 B 各自：SD(k_max) < SD(k=1) 的单元占比 ≥ 80% |
| **Z3** | A、B、D 三者的 Z1/Z2 方向**一致**（即单元效应不是 iForest 特有） |
| **Z4**（描述） | 三个检测器在 k=1 时的均值误报率水平 |

判定：Z1/Z2 对 A、B 成立且 Z3 方向一致 → "单元效应跨检测器成立"，可写入论文。

## 4. 措辞纪律

- 三个检测器都在**同一检测范式**内（阈值取训练分数分位），**不得**据此声称"对任意检测器成立"；
- 仍只有两个 run-to-failure 数据集、6 个工况单元，不得做跨设备泛化；
- 若某检测器不成立，如实报告并**限定结论范围**，不得只报成立的两个。

## 5. 运行规模

RMS 与马氏距离拟合在毫秒级，本实验预计 **1–3 分钟**（远低于 EXP-V2-05 的 20 分钟）。

`experiments/EXP-V2-06-multi-detector.md`、`-raw.csv`、`-summary.csv`、`-run-log.txt`、哈希文件，
并执行 ①–③ 三层验证。
