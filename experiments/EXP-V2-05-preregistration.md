# EXP-V2-05 预注册：工况内分层的独立单元对照（拆解 V2-04 的混杂）

- 日期：2026-09-19
- 状态：**在运行之前冻结并提交**
- 触发：2026-09-19 计划审查发现 EXP-V2-04 的 S3 臂**未按工况分层**，
  导致"训练轴承数 k"与"工况多样性"混杂（实测：k=1 时 100% 只含单一工况，
  k=12 时必然跨 3 个工况）。**主结论的第二层因此不可解释。**

## 1. 要回答的问题

> EXP-V2-04 中"SD 随训练轴承数 k 下降 3–4 倍"，有多少来自**独立单元数增加**，
> 有多少来自**工况多样性增加**？

## 2. 设计：把 k 限制在**单一工况内部**

| 项 | 设定 |
| --- | --- |
| 训练轴承来源 | **仅来自与被测轴承相同的工况**（工况数恒定 = 1） |
| 折 | 每工况内 leave-one-bearing-out（训练与测试同工况、不同轴承） |
| S3' 臂 | 固定 20 条记录，k = 1 … min(4, 可用轴承数−1) |
| 检测器 / 阈值 / 种子 | iForest(200, 0.5) / q = 0.99 / 固定 |
| 重复 | 每格 R = 50 |

**可用轴承数（实测）**：

| 数据集 | 工况 | 纳入轴承 | 工况内可用 k |
| --- | --- | ---: | --- |
| XJTU-SY | 35Hz12kN / 37.5Hz11kN / 40Hz10kN | 各 5 | 1–4 |
| PRONOSTIA | Bearing1_x（7）/ Bearing2_x（7）/ Bearing3_x（3） | 7 / 7 / 3 | 1–6 / 1–6 / 1–2 |

## 3. 判据（先冻结）

| 编号 | 判据 | 含义 |
| --- | --- | --- |
| **Y1** | 每个（数据集 × 工况）单元内，SD 随 k 下降（Spearman < 0）的单元占比 ≥ 80% | 工况恒定下独立单元效应存在 |
| **Y2** | SD(k_max) < SD(k=1) 的单元占比 ≥ 80% | 极端对照 |
| **Y3（关键）** | 记 R_within = SD(k=1)/SD(k_max)（工况内），R_mixed = 同数据集在 V2-04 中的对应比值（跨工况）。比较 R_within 与 R_mixed | 判定效应的归属 |

判定规则：

- **R_within 与 R_mixed 量级相当**（比值 ≥ 0.6）→ 独立单元效应**独立成立**，
  第二层结论保留，V2-04 的混杂不影响结论方向；
- **R_within 明显小于 R_mixed**（比值 < 0.6）→ V2-04 的效应**主要来自工况多样性**，
  **第二层必须改写为"工况多样性效应"**，v1.7 §二需修订；
- **R_within ≈ 1**（无效应）→ 效应完全归因于工况多样性。

## 4. 措辞纪律

- 本实验**不得**用于"证明 V2-04 有错"——V2-04 的实验本身没有执行错误，
  问题在于**设计未控制一个已知变量**；
- 无论结果如何，都必须在论文中报告这个混杂及其对照结果；
- 工况内样本量很小（每工况 3–7 颗轴承），**不得**据此做跨工况泛化声明。
