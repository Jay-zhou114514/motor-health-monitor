# EXP-V2-02 预注册修订 1：记录长度不一致的统一处理

- 日期：2026-09-17
- 状态：**在 EXP-V2-02 正式运行之前提交**
- 触发：首次运行时抛出 `ValueError: 信号太短，无法切出完整窗口`

## 1. 事实

480 条记录（4 工况 × 6 轴承 × 20 条）的 `vibration_1` 长度分布：

| 统计 | 值 |
| --- | --- |
| 中位数 / 众数 | 256,001 点（4 s @ 64 kHz） |
| 最小 | **255,996 点** |
| 最大 | 291,847 点 |
| **< 256,000 的记录数** | **2 条**（`N09_M07_F10_K002_6.mat` = 255,999；`N15_M07_F04_K002_16.mat` = 255,996） |
| < 240,000 的记录数 | 0 |

即：所有记录都约 4 秒，但**长度不严格相等**（±最多 0.036 s 的抖动）。

## 2. 统一处理（本修订冻结）

> 每条记录**截断到前 `min(len(signal), 256,000)` 个采样点**，
> 并在该长度上计算一次窗口（`window_sec = step_sec = n / 64000`，n 为该记录的可用点数）。

具体效果：

- 478 条记录：使用前 256,000 点（= 4.0 s），与 EXP-V2-01 主分析**完全一致**；
- 2 条记录：分别使用 255,999 / 255,996 点（比 4 s 少 4 个采样点，相对差 **0.0016%**）。

## 3. 为什么这样处理（而非其他方案）

| 备选 | 否决理由 |
| --- | --- |
| 统一降到 255,996 点 | 会让 EXP-V2-01 的既有结果失去可比性，需要重跑主分析，收益仅为 4 个采样点 |
| 丢弃 2 条短记录 | 会改变各轴承的记录数（从 20 变成 19），破坏"每轴承 20 条"的整齐结构 |
| 补零 / 重复填充 | 会人为改变信号的统计特性（kurtosis / crest 对边界敏感） |
| **截断到 min(len, 256000)**（采用） | 与主分析保持一致；偏差有界且可量化 |

## 4. 影响评估（先声明）

- 4 个采样点（0.0625 ms）在 4 s 记录上不会实质改变 rms / crest / kurtosis / 谱心；
- 但仍必须记录：这 2 条记录的特征与"严格 4 s"相比存在**微小**差异；
- 若 V2-02 的结果对某个工况的结论依赖于这 2 条记录，须在记录中显式标注。

## 5. 不变项

判据 R1–R4、S1/S2 构造、n 扫描、R = 100、测试集切分全部不变。
