# EXP-V1-10 预注册修订 1（零模型 + 分数层指标）

- 日期：2026-09-17
- 状态：**在 EXP-V1-10 任何结果产生之前提交**
- 关系：本文件**不修改** `EXP-V1-10-preregistration.md` 已冻结的 R = 50、固定测试文件、候选网格与判定 P1 / P2 / P3；只**新增**实验臂与指标，并修正原文已自行声明的一处尺度矛盾。

## 1. 为什么要修订（两个必须在运行前解决的问题）

**R1 分辨率矛盾。** 主分析的测试集只有 2 个文件 × 7 窗口 = 14 个窗口，FP rate 的取值只能是 0、1/14、2/14 …，
相邻取值相差 7.14 个百分点，最小非零标准差约 3.57 个百分点。
原 P2 的阈值（2 个百分点）虽然可被触发，但只能以 3.57 个百分点的台阶跳变，
因此**“稳定性”在二值尺度上几乎不可分辨**。原文 §5 已声明该限制，但未给出替代测量方式。

**R2 归因缺口。** 即使观察到重复之间的波动，也无法区分它来自：
（a）数据 / 装置结构；（b）仅仅来自有限样本噪声。没有零模型，Layer 3 的因果措辞无法收敛。

## 2. 新增 A1：分数层（连续）指标

对每个复制的每个窗口，记录其在**拟合集分数经验分布**中的分位：

```text
p = F_fit(s) = #{训练分数 ≤ s} / n_train
```

该量对配置的分数尺度不变，因此**可跨配置比较**（原始分数不可比）。记录：

| 字段 | 含义 |
| --- | --- |
| `test_pct_mean` | 固定测试集窗口分位的均值（**主连续指标**） |
| `test_pct_max` / `test_pct_q90` | 同一量的上尾统计 |
| `val_pct_mean` | 验证集的同一量 |
| `test_fp_rate` | 原冻结的粗尺度指标（保留） |

**新增判据 P4**：`test_pct_mean` 在 R 次重复间的标准差 > 0.02（2 个百分位点）
→ 选择过程的波动在**连续尺度上可被观测到**。

说明：P4 不是 P2 的替代判定，而是 P2 的量纲对照。两者必须分别报告。

## 3. 新增 A2：并列统计

记录每次复制中**达到最小验证 FP 的候选配置个数** `n_tied_at_min`。

**新增判据 P5**：`n_tied_at_min ≥ 2` 的复制占比 ≥ 0.25
→ 选择准则经常**无法区分**最优配置，即这些复制上的"选择"在准则意义上本质是任意的。

并列时按冻结网格顺序决定，与测试集无关。

## 4. 新增 A3：零模型（噪声基准）

使用**完全相同的协议**（R = 50、同样的 fit / validation 划分种子、同样的网格、同样的选择与并列规则），
只把 10 个文件的**窗口替换为合成窗口**：

| 代号 | 零模型 | 构造 |
| --- | --- | --- |
| N1 | 非参零模型 | 把 10 个文件的全部窗口汇入池，按每个真实文件的窗口数**有放回**抽窗构造伪文件（破坏文件身份，保留边缘分布与依赖结构） |
| N2 | 参数零模型 | 对汇入池的 4 维特征估计均值与 Ledoit–Wolf 协方差，按同样的窗口数独立抽 N(μ, Σ) |

每个零模型重复 M = 100 个**独立伪数据集**，每个伪数据集内跑 R = 50 次重采样。
零模型的评估**仍使用真实的固定测试集**，保证与主分析可比。

**新增判据 P6**：真实主分析的模态配置占比落在 N1 零模型分布的 5%–95% 区间内
→ 观察到的选择不稳定**与有限样本噪声不可区分**。
此时 Layer 3 的措辞必须改为"**样本量驱动**"，不得写成"数据 / 装置结构驱动"。

## 5. 新增 A4：方差分解（选择过程 vs 测试集）

| 设计 | 训练池 | fit / validation / test | 说明 |
| --- | --- | --- | --- |
| A（冻结主分析） | 10 个文件 | 7 / 3 / **固定 2 个真实文件** | 测试集固定 → 重复间波动**只能**来自选择过程 |
| B（新增） | 12 个文件 | 7 / 3 / 2（测试集也重采样） | 与 A 规模相同，唯一差别是测试集是否固定 |

**新增判据 P7**：设计 B 的 `test_fp_rate` 标准差 ≥ 设计 A
→ 总波动不小于仅选择波动。若 B ≈ A，则说明在该规模下"换测试集"带来的波动
并不大于"换验证集导致的选参变化"。

## 6. 新增 A5：R 依赖性检查

主分析保持冻结的 R = 50。另跑 **R = 200** 作为精度检查，用来确认"不同配置个数"这一指标对 R 的机械依赖
（原 P1 的第二条子判据"不同配置数 ≥ 3"会随 R 增大而更易满足）。
报告时两条子判据必须**分开写**，不得合成一个"成立 / 不成立"。

## 7. 新增 A6：方法扩展（次要）

同一协议下对 **RBF One-Class SVM**（沿用 V1-09 冻结网格）重复上述过程，
检查"选择过程不稳定"是否为 iForest 特有。作为**次要结果**，不参与主判定。

## 8. 保持不变（仍按原预注册执行）

1. 固定测试集 = IMS `1st_test` 中按文件名排序的**前 2 个文件**
   （`2003.10.22.12.06.24.txt`、`2003.10.22.12.09.13.txt`）；
2. 训练池 = 其余 10 个文件；R = 50；7 fit / 3 validation；随机种子序列固定；
3. 阈值 = 训练分数 0.99 分位数；候选网格 = V1-09 冻结网格；
4. 对照：3σ RMS 与"默认配置 iForest（`n_estimators=200, max_samples=0.8`，不搜索）"在同一固定测试集上的结果；
5. 判定 P1 / P2 / P3 按原文，**不得回改**。

## 9. 解读规则（先于结果）

1. P4 成立而 P2 不成立 → 只能写"波动在连续尺度可见，但在 14 窗口的二值尺度上不可分辨"，**不得**写"性能不稳定"；
2. P2 成立而 P4 不成立 → 必须先检查是否为单一复制的离群所致，不得直接写"传导到性能"；
3. P6 不成立（真实值超出零模型的 5–95% 区间）→ 只能写"超出噪声基准"，
   跨体系结论仍需 V2 的案例层证据，不得据此谈外部效度；
4. 本实验证据等级上限为 **Level B**（单一试验台、单一批次、固定测试集）；
5. 失败与零结果保留；无论结论如何，"选择过程应被报告"这一**表述规范**主张不受本实验存亡影响，
   但它的**量化强度**必须按 P1–P7 的实际结果书写。
## 10. 判定组合表（先于正式运行写定，不修改任何预测）

**背景是协议自身的性质，不是数据结果**：并列规则是确定性的（按冻结网格顺序），
因此当"所有候选配置的验证误报同为 0"时，选择结果必然落在网格第一项。
这意味着 **P1（模态占比）在准则不判别的情形下会机械地偏高**，
不能反过来解读为"选择过程稳定"。缺少本节，P1 的失败会被误读。

| P1（模态占比 < 50%） | P5（并列占比 ≥ 25%） | 必须照此书写的解读 |
| --- | --- | --- |
| 不成立 | 成立 | 选择过程**并非稳定，而是准则不可分辨**：验证集太小，无法区分候选配置，最终配置由并列规则决定。Layer 3 的量化依据为 P5（并参考 P2 / P4）。 |
| 不成立 | 不成立 | 选择准则能区分候选配置，且结果一致 → Layer 3 的**不稳定主张不成立**；只能写"在单一批次、该网格与样本量下未观察到选择不稳定"。 |
| 成立 | 成立 | 既不可分辨、结果又发生改变 → Layer 3 依据 P5 与 P1 共同书写。 |
| 成立 | 不成立 | 准则可分辨但结果仍摇摆 → 这是支持的**最强**形式。 |

补充规定：

1. 无论 P1 结果如何，**必须同时报告 P5 与并列集合大小**，否则 P1 无法解释；
2. 若并列占比 ≥ 25%，"模态占比"**不得单独作为结论依据**；
3. 本节在正式运行之前写定：另有一次 **R = 3 的冒烟运行**，仅用于验证代码路径可跑通，
   不作为结果、不进入任何 CSV 结论、也未用于修改任何预测；该事实同样记录在实验记录中。
