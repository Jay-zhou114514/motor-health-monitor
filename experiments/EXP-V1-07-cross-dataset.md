## 1. 数据与设计

| 批次 | 健康文件 | 采样率 | 窗口 |
| --- | ---: | --- | --- |
| IMS 1st_test | 12 | 20 kHz | 0.25 s / 0.125 s（修订 1） |
| IMS 2nd_test | 6 | 20 kHz | 同上 |
| IMS 4th_test | 6 | 20 kHz | 同上 |
| MFPT（MathWorks） | 3 | 97.656 kHz | 1.0 s / 0.5 s |

- 独立单元按修订 2 = **试验批次**（3 个 IMS 批次 + 1 个 MFPT）；
- 批次内做 leave-one-file-out；每个折叠记录条件数、阈值、膨胀比、FP rate；
- 协方差方案：经验（δ=0）、Ledoit–Wolf（C3）、条件数 ≤ 100（C5）；
- 强制稳健性：IMS 另用 0.5 s 窗重跑。

## 3. Observation 与 Interpretation

**Observation（事实）**

1. 在 3 个独立 IMS 批次（共 24 个健康文件、24 个折叠）上，
   **问题组的膨胀比从未超过 1**，FP rate 在 2.4%–14.3% 之间。
2. 收缩在 3/3 个 IMS 批次上都降低了膨胀比（+0.058 ~ +0.214），方向与 MFPT 一致。
3. MFPT 上问题组经验协方差的膨胀比中位数是 0.797——
   **即 MFPT 自身在 LOFO 下也没有整体膨胀**；
   EXP-V1-05/06 观察到的 1.576 只出现在"留出 baseline_3"这一特定折叠。
4. 收缩在个别批次上略微增加了 FP（1st_test 问题组 2.4% → 3.6%）。

**Interpretation（初步解释，待审查）**

1. **H2 的"修复"叙事不成立（退化性结果）**：
   收缩必然会缩小马氏距离，因此"Δ 膨胀比 > 0"是**机制上的必然结果**，
   不能作为"修复了某个问题"的证据。要证明修复，必须先观察到膨胀存在——
   而本次三个独立批次**都没有出现膨胀**。
2. **原失效模式没有复现**：MFPT 上那个 1.576 的膨胀只出现在单一折叠
   （留出 baseline_3），在 IMS 的三个独立批次中完全没有出现。
   这强烈提示：该现象更像是 `baseline_1/2 → baseline_3` 这一对文件的
   **特定差异**，而不是 RMS+质心几何的普遍性质。
3. 因此，EXP-V1-05/06 的机制结论应进一步降级：
   从"Level B 工作假说"降为**"仅在单一数据集、单一文件对下观察到的个案"**。

## 4. Limitation

1. IMS 的 3 个批次同属一类试验台设计，仍非"不同设备"级别的独立性；
2. IMS 无逐文件故障标签，只能评价正常数据的膨胀与误报；
3. 各批次窗口长度不同（0.25 s vs 1.0 s），虽已做 0.5 s 稳健性检查；
4. 每批次内文件时间相邻，批次内相关性仍然存在（已在修订 2 中声明）。

## 5. 结论（草案，待项目负责人审查）

- **P1 不成立**：所声称的失效模式（距离膨胀导致大量误报）在三个独立批次上**未复现**；
- P2/P3 的"成立"是退化性的，不能作为支持 H2 的证据；
- 建议把主线从"机制 + 修复"改为**负结果 / 评价方法学**：
  "一个在单数据集上看似显著的失效模式，在跨批次验证下不复现；
   因此报告此类机制前必须做跨批次/跨设备验证与功效分析。"
