# EXP-V2-01 预注册：跨数据体系下的误报率不确定性缩放

- 日期：2026-09-17
- 状态：**在运行之前冻结并提交**
- 定位：V1→V2 门控的案例层证据；**不是**为了证明某个机制，而是检验一条标度关系

## 1. 研究问题（按项目负责人意见修正后的措辞）

> **在不同数据体系下，仅用健康数据训练的轴承异常检测，
> 其误报率估计的不确定性是否呈现相似的非理想缩放行为？**

核心子问题（本实验的真正落点）：

> **名义样本量 n 的增长，是否等价于有效信息量的增长？**

即：当 n 的增长来自"**更多真实记录**"时，
误报率的估计不确定性是否像 EXP-V1-11 中那样**早早饱和**？
还是说 EXP-V1-11 的饱和只是"在固定有限总体内反复重采样"的必然结果？

**注意措辞纪律**：本实验**不写成**"证明 1/√n 律失效"。
1/√n 律失效是 EXP-V1-11 在一个特定设置下的观察；
本实验检验的是"非理想缩放是否跨体系重现"，允许结果为**否**。

**关键含义**：每条记录是一个**短片段**，不切多个窗口。
因此本实验里 **记录数 = 样本数**，"单元类型"与"窗口数"不再混淆——
这是 EXP-V1-11 的 P3 变体设计缺陷在 V2 被消除的地方。

可用真实记录：6 个健康轴承 × 20 条 = **120 条真实记录/工况**。
固定工况 `N15_M07_F10` 作为主分析（其余工况作为稳健性检查，不计入主判定）。

## 3. 设计：两个 n 增长来源的对照

这是本实验与 EXP-V1-11 的本质区别。

| 臂 | n 增长来自 | 构造 |
| --- | --- | --- |
| **S1 重采样增长**（复现 V1-11） | 同一有限总体内**有放回**重复采样 | 从固定子集（例如 20 条记录）中有放回抽 n 条 |
| **S2 真实新增增长** | **追加不同的真实记录** | 从 120 条记录中**无放回**取 n 条（n = 5…100） |

**其余全部固定**：检测器 iForest(200, 0.5)；阈值分位 q = 0.99；特征沿用冻结的 4 个；
测试集 = 从 120 条中预留的**固定 20 条**（全程不参与训练）；
随机种子固定为 0（隔离种子来源，它已由 EXP-V1-10 方差分解处理）。

**n 扫描**：{5, 10, 20, 40, 60, 80, 100}（S1 与 S2 使用同一组 n，便于直接比较）。

**每格重复** R = 150。

## 4. 指标

| 指标 | 定义 |
| --- | --- |
| SD(误报率) | 重复间测试误报率的标准差（以百分点计） |
| **n_eff** | `q(1-q) / SD²`（由阈值估计误差的经典结果反解） |
| **efficiency** | `n_eff / n`（有效信息量占名义样本量的比例） |
| 连续指标 | 测试分数的训练分位均值（摆脱 1/20 量化下限） |

**关于量化下限**：测试集 20 条 → 误报率分辨率 5 pp，
单次观测的量化下限会使 SD 存在地板（约 2.5 pp）。
因此**主判定使用 n_eff 与 efficiency 的趋势**，不比较绝对值。

## 5. 预定义判据

| 编号 | 判据 | 若成立意味着 |
| --- | --- | --- |
| **P1** | S2（真实新增）的 `n_eff` 随 n **持续增长**（Spearman > 0 且末点 > 首点 2 倍） | 真实新增数据确实带来新信息 |
| **P2** | S1（重采样）的 `n_eff` **饱和**（末点 / 首点 < 2，且出现非单调） | 复现 EXP-V1-11 的饱和现象 |
| **P3** | 相同 n 下，`efficiency(S2) > efficiency(S1)` | 名义 n 相同、有效信息不同 → **支持核心命题** |
| **P4** | S2 的 SD−n 斜率比 S1 更接近 −0.5（log-log 回归） | 缩放更接近理想律（仅描述，不作强结论） |

判定：

- **支持核心命题**：P1 与 P3 成立 → "名义样本量 ≠ 有效信息量"在第二个体系中重现；
- **部分支持**：仅 P3 成立；
- **不支持**：P1 或 P3 不成立 → EXP-V1-11 的饱和被解释为"固定总体 + 重采样"的假象，
  必须回到 EXP-V1-11 记录更正，且**不得**在论文中把它写成一般性结论。

## 7. 限制（预先声明）

1. Paderborn 的 6 个健康轴承**来自同一试验台**，只是不同物理轴承单元；
   "跨体系"指的是"IMS vs Paderborn"，不是"跨设备泛化"；
2. 每工况 20 条记录、6 个轴承 → 独立轴承单元只有 **6 个**，
   因此本实验的 n 增长在"记录维度"成立，在"轴承维度"仍然很小；
3. 不同工况的转速/负载不同，主分析固定单一工况；跨工况只作稳健性检查；
4. 采样率与记录长度与 IMS 不同 → 禁止把两边的 SD 绝对值直接对比，
   只能比 **efficiency 与缩放趋势**；
5. 若 Paderborn 记录数不足或特征提取失败，如实记录失败，不得替换为模拟数据。
