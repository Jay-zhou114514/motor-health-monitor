# EXP-V3-03 预注册：从 marginal 到 unit-level 覆盖——四种分层校准的公平对照

- 日期：2026-09-22
- 状态：**在运行之前冻结并提交**
- 触发（用户修正，采纳）：EXP-V3-01 的负结果只能支持
  "**仅靠全局阈值校准，一般不能保证异质或漂移条件下的单元级条件覆盖率**"，
  **不能**支持"阈值校准救不了单元级不确定性"（后者过绝对：conditional / localized /
  weighted / group-conditional conformal 与 hierarchical calibration 都可能改善）。
  本实验用**同一协议**公平检验这些族的代表方法。

## 1. 现象的形式化（论文的理论动机）

$$\underbrace{P(\text{score}\le t)\ge 1-\alpha}_{\text{marginal}}
\;\not\Rightarrow\;
\underbrace{P(\text{score}\le t\mid G=g)\ge 1-\alpha}_{\text{group / unit-level}}
\;\not\Rightarrow\;
\underbrace{P(\text{score}\le t\mid X=x)\ge 1-\alpha}_{\text{conditional}}$$

已知：分布无关的条件覆盖不可达；group-conditional（Mondrian）需要**组内校准样本**；
weighted conformal 在协变量漂移与可估权重的条件下可改善目标分布的覆盖。

## 2. 关键结构性问题（本实验要检验的核心）

对**未见过的物理单元**，"组 = 该单元自身"时**没有任何组内校准样本**——
因此 unit-level 条件覆盖在"不给目标单元数据"的前提下**缺乏支持（no support）**。

本实验把"条件层级"与"可用校准数据"显式分开：

| 层级/组定义 | 组内可用的校准单元（留一后） | 是否给目标单元数据 |
| --- | --- | --- |
| **L0 全局**（B1 池化分位） | 全部训练单元混合 | 否 |
| **L1 条件级**（同数据集同工况） | 3–6 颗 | 否 |
| **L2 单元级（他单元代理）** | 0（新单元无同单元校准样本） | 否 |
| **L3 单元级（自校准）** | 目标单元自身健康记录 | **是**（即 within-bearing 口径） |

**预期（作为待检验假设，不是结论）**：L0/L1 缺乏支持 → 难以达到单元级覆盖；
L3 在覆盖上可达，但代价是**对未来的新单元乐观**（这正是 EXP-V2-03 的 0.00% vs 40.63%）。

## 3. 对照方法（先冻结）

| 代号 | 方法 | 组定义 | 需要估计的量 |
| --- | --- | --- | --- |
| **M0** | B1 全局池化分位（基线，marginal） | — | 无 |
| **M1** | **Mondrian / group-conditional conformal** | 组 =（数据集 × 工况） | 组内校准分位 |
| **M2** | **Weighted conformal**（权重 = 训练分数分布 → 目标单元分数分布的密度比） | 全局 + 权重 | 密度比（logistic 分类器估计，训练内交叉拟合） |
| **M3** | **Localized conformal**（在特征空间取目标单元最近的 k 个校准单元） | 邻域 | 邻域大小 k |
| **M4** | **Hierarchical calibration**（全局 + 组级两层收缩，收缩系数由训练内 LOO 选） | 全局 + 组 | 收缩系数 λ |
| **M5** | **L3 自校准**（用目标单元前 10 条健康记录校准，仅作上界） | 单元自身 | 无 |

## 4. 主指标（改为覆盖率——这是 conformal 语言的正确度量）

| 指标 | 定义 |
| --- | --- |
| **C1 单元级覆盖率** | 实际误报率 ≤ α（1%）的**测试实例比例**，附 **Wilson 95% CI** |
| **C2 覆盖偏差** | 实际误报率与 α 的平均绝对偏差（pp） |
| **C3 覆盖率的分层差异** | 按数据集 / 检测器分层的覆盖率之差（检验"层级依赖性"） |
| **C4 退化标记** | 率 = 0 或 1 的实例（饱和）单独报告 |

**旧指标（跨单元 SD）作为次要指标同时报告**，以便与 EXP-V3-01 对照。

## 5. 判据（先冻结）

| 编号 | 判据 | 判定 |
| --- | --- | --- |
| **H11** | M1（Mondrian）相对 M0 的 C1 提升 ≥20 个百分点，且在 ≥2/3 单元集合上方向一致 | 支持 / 部分 / 不支持 |
| **H12** | M2（Weighted）相对 M0 的 C2 降低 ≥50% | 支持 / 部分 / 不支持 |
| **H13**（关键） | **在"不给目标单元数据"的前提下，没有任何方法达到名义覆盖率**（C1 ≤ 0.5×名义覆盖或 C2 ≥ 5 pp） | 支持（负结果）/ 不支持 |
| **H14** | M5（自校准，给目标单元数据）的 C1 ≥ 0.9×名义覆盖，且显著优于 M0–M4 | 支持 / 不支持 |

**否证条件**：若 H11 或 H12 成立（即有方法在无目标单元数据下改善覆盖），
则论文必须**撤回**"缺乏支持"的强表述，改为"在本文数据规模下，X 方法可部分改善，其余方法不可"。

## 6. 三层验证与实现要求（防退化）

- **L1**：率 ∈ [0,1]、无 NaN、**训练集不含测试实例**（集合断言）、组内校准单元计数、
  收缩/邻域参数在预定义网格内、窗口数 >500；
- **L2**：另一条代码路径复算 C1/C2/C3；
- **L3**：确定性重跑逐字节比对（排除计时列）；
- **实现纪律**：所有校准只使用训练侧数据；M2 的密度比必须**交叉拟合**（避免用目标单元自身估计权重）；
  M3 的邻域必须只看训练单元；M5 明确标注为"上界/自校准"，不得与 M0–M4 混为一谈。
