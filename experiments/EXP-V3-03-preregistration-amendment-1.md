# EXP-V3-03 修订 1：M5 自校准的"目标数据量"扫描

- 日期：2026-09-23
- 状态：**在运行之前冻结并提交**
- 触发：EXP-V3-03 的主结果显示 **M5（用目标单元自身健康数据自校准）在双侧带宽下是唯一
  稳定有效的方法**（严格带宽命中率 0.21–0.29，而全局校准仅 0.00–0.08）。但 M5 只用了
  目标单元的**前 10 条记录**（分辨率 10%，明显偏粗），因此需要回答：

> **要让单元级校准达到可用的准确性，需要多少"目标单元自己的健康数据"？**

## 1. 设计与指标（先冻结）

- 数据与协议同 EXP-V3-03（Paderborn，620 窗/实例，P1 严格留出整颗轴承）；
- 校准规模 $c \in \{10, 31, 155, 310, 465\}$ 个窗口（≈记录 0.3、1、5、10、15 条）；
  用**目标实例的前 $c$ 个窗口**校准阈值，在**其余 $620-c$ 个窗口**上评估；
- 指标（双侧口径，见 `exp_v3_03_metrics_fixed.py`）：
  - **B_tight** = 率落在 $[0.5\alpha, 1.5\alpha]$ 的实例比例（主指标）；
  - **B_wide** = 率落在 $[0.25\alpha, 2\alpha]$ 的比例；
  - **mean_dev** = 平均 $|率-\alpha|$（pp）；
  - **over** = 率恰为 0 的实例比例（过度保守，单独报告）；
  - 对 B_tight 给 **Wilson 95% CI**。

## 2. 判据

| 编号 | 判据 | 判定 |
| --- | --- | --- |
| **H20** | 存在 $c^\*$ 使 **≥2/3 检测器**的 B_tight ≥ **0.50** | 支持 / 部分 / 不支持 |
| **H21** | mean_dev 随 $c$ 增大而下降（Spearman < 0，且 ≥2/3 检测器成立） | 支持 / 不支持 |
| **H22** | 达到 B_tight ≥ 0.50 所需的 $c^\*$ 不超过实例窗口数的一半（即"用一半目标数据即可"） | 支持 / 不支持 |

**否证条件**：若在最大 $c=465$（75% 窗口）下 B_tight 仍 <0.30，则"自校准可行"的主张必须
削弱为"自校准可改善偏差，但仍不足以稳定落在 ±50% 带宽内"。

## 3. 实现与验证

- 复用 EXP-V3-03 的实例构建与检测器分数函数；
- 校准只用目标实例的前 $c$ 个窗口，评估只用其余窗口（**不得重叠**，脚本内断言）；
- L1：率 ∈ [0,1]、无 NaN、$c$ 在网格内、窗口计数 $c + (620-c) = 620$；
- L2：另一条代码路径复算 B_tight / mean_dev；
- L3：确定性重跑逐字节比对（排除计时列）。
