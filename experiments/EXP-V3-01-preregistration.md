# EXP-V3-01 预注册：面向未见物理单元的阈值校准（Unit-Level Threshold Calibration, ULTC）

- 日期：2026-09-21
- 状态：**在运行之前冻结并提交**（本文件先提交，脚本与结果随后）
- 触发：CCDC 补救计划阶段 0——现有工作的短板是"没有方法增量"；本实验把已发现的问题
  （报告的误报率在跨物理单元时极不稳定，SD 44.8 pp、0.00%→97.10% 双峰）转成一个**可执行的方法**。
- 关联：`EXP-V2-03`（口径效应）、`EXP-V2-05/06`（单元效应与饱和）、`EXP-V1-05/06`（协方差正则化）。

## 1. 要回答的问题

> 在仅用健康数据训练的单类轴承监测中，**把报警阈值改为"在训练单元之间校准"而不是
> "在训练分数上取分位"**，能否降低报告误报率在**未见过的物理单元**上的离散度，
> 并把达成率拉近到名义目标（1%）？

这不是新检测器，而是**阈值确定的程序（calibration procedure）**；检测器本身保持冻结
（3σ RMS、马氏距离、Isolation Forest）。

## 2. 方法（先冻结）

### 2.1 ULTC 定义

设训练集包含 $n$ 颗健康轴承（**单元**）。对每颗训练轴承 $i$：

1. 用**其余 $n-1$ 颗**轴承的健康记录拟合检测器（leave-one-unit-out，训练内部，不触碰测试单元）；
2. 在被留出的轴承 $i$ 的**全部健康窗口**上计算分数，取其 $(1-\alpha)$ 分位数 $t_i$（$\alpha = 0.01$）；
3. 得到 $\{t_1,\dots,t_n\}$ 后，阈值取：
   - **ULTC-mean**：$t^\*=\mathrm{mean}_i\,t_i$
   - **ULTC-max**：$t^\*=\max_i t_i$（更保守，覆盖全部训练单元）

两个变体都**只使用训练单元的数据**，不使用任何测试单元，也不使用测试集信息。
选择哪个变体是**方法参数**，在本预注册中固定为"两个都报，主变体为 ULTC-mean"。

### 2.2 对照（基线）

| 代号 | 阈值规则 | 备注 |
| --- | --- | --- |
| **B1** | 训练分数池化的 0.99 分位 | 现行标准做法（`FROZEN_PROTOCOL` §4） |
| **B2** | Ledoit–Wolf 收缩协方差 + B1 | EXP-V1-05/06 的既有发现 |
| **B3** | 训练内准则"最小 δ 使条件数 ≤ 100" + B1 | 仅用于马氏距离 |

### 2.3 检测器与特征

冻结：四个特征（`rms`, `crest_factor`, `kurtosis`, `centroid_hz`）；检测器 3σ RMS、马氏距离、
Isolation Forest(200, 0.5)。**不新增特征、不新增检测器。**

### 2.4 折与数据划分

- 每个"数据集 × 工况"单元集合内做 **leave-one-unit-out**：训练用 $n-1$ 颗，测试用被留出的那颗；
- 记录预算固定为 20 条记录（与 EXP-V2-05/06 一致，便于对比）；
- 数据集合：PRONOSTIA（3 个载荷）、XJTU-SY（3 个工况）、Paderborn（6 颗健康轴承）、IMS（3 个批次）；
- **测试单元只用于最终评估**，ULTC 的 $t_i$ 全部来自训练单元。

## 3. 指标（先冻结）

| 指标 | 定义 | 角色 |
| --- | --- | --- |
| **M1 跨单元 SD** | 各留出单元的误报率的样本标准差（折间口径） | 主指标 |
| **M2 达成偏差** | \|实际误报率 − 名义 1%\| 的均值（pp） | 次指标 |
| **M3 命中率** | 落在 [0.5%, 2.0%] 的留出单元比例 | 次指标 |
| **M4 训练单元数敏感性** | $t^\*$ 随训练单元数（1…k_max）变化的斜率 | 稳健性 |

统计：对 M1 的组间差做 **bootstrap 95% CI（10,000 次，以单元为重采样单位）**与
**置换检验（10,000 次）**，固定种子 20260921。

## 4. 判据（先冻结）

| 编号 | 判据 | 判定 |
| --- | --- | --- |
| **H1** | ULTC-mean 的 M1 相对 B1 下降 ≥50%，且在 **≥3/4** 数据集上方向一致 | 支持 / 部分 / 不支持 |
| **H2** | ULTC-max 的 M2 ≤ 1.0 pp，且 M3 ≥ 80% | 支持 / 部分 / 不支持 |
| **H3** | ULTC 与 B2 的差异不显著（p > 0.05） | 说明 ULTC 不优于正则化基线（须如实报告） |

**否证条件**：若 M1 的下降 <25% 出现在 ≥2 个数据集上，H1 判为**不支持**，方法主张撤回。

## 5. 退化与饱和的处理（落实反模式 7 与 11）

- 若某留出单元在某配置下**全报警（率 = 100%）**或**零报警**，其分辨率由测试记录数决定；
  该值**如实记录**，但在 M1 计算中标记 `saturated` 并**单独报告**；M1 主值仅在未饱和单元上计算，
  同时给出含饱和单元的值作为敏感性。
- 若 $\mathrm{SD}=0$（退化稳定），不参与比值计算，并在结果表中显式标记。
- 马氏距离在 $n=1$ 时无法做 leave-one-unit-out（无训练单元可留出）：该配置标记
  `not_testable`，不进主分析。

## 6. 三层验证要求

按 `docs/REPRODUCIBILITY_PROTOCOL.md`：

- **L1**：误报率 ∈ [0,1]、无 NaN、留出单元计数完整、$t^\*$ 随 $\alpha$ 单调、训练/测试单元不重叠；
- **L2**：用**另一条代码路径**重算 M1/M2/M3（例如直接用原始 CSV 与独立实现），逐项比对；
- **L3**：确定性重跑，SHA-256 逐字节比对，**排除非确定性列**（计时列）。

## 8. 措辞纪律（预注册即约束）

- 本实验**不得**用于主张"新检测器"；它主张的是**阈值确定程序的改变**；
- 若 H1 只在部分数据集成立，必须写成"在 X/4 数据集上成立"；
- 不得把 ULTC 说成"保证"目标误报率；只能说"在训练单元上校准"，其外推能力由 M1 量化。
