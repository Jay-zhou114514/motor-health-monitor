## 3. Observation

1. **S2（真实新增）在全部 4 个工况上单调下降**，且这是本实验最强的规律：
   n = 10 时 5.8–7.5 pp → n = 96 时 0.00–0.93 pp。
2. **S1（重采样）在 3 个工况上饱和**（M01 几乎完全不动：15–21 pp；F10 18 pp；F04 8–12 pp），
   **在 N09 上却同样收敛到 0**——这是 R1 失败的来源。
3. **例外工况 N09 有清晰的机械解释**：该工况下两臂的**均值误报率本来就低**
   （n = 20 时 S1 仅 1.25%），测试分数整体远离阈值，
   因此"越过阈值的窗口数"本来就接近 0，方差自然塌缩——
   **不是因为重采样变成了有效信息**。
4. 主分析的"约 60 条记录 → SD ≤ 1 pp"**未能跨工况成立**：
   按 n = 80 计是 3/4（N09 = 1.09 pp 略超），按 n = 96 计是 **4/4**。

## 4. Interpretation

1. **定性对比稳健，定量处方不稳健**：
   "真实新增记录 ≫ 重采样"的方向在 3/4 工况成立，且 4/4 工况下 S2 单调收敛；
   但**具体需要的记录数依工况而定**（60 → 80–96 条），
   因此论文中**不得**给出单一数字，必须写成条件依赖。
2. **例外可由机制解释，而非反例**：N09 的 S1 收敛是"没有误报可波动"的退化，
   与"重采样带来信息"是两回事。这需要在论文中显式区分。
3. **R2 的严格判据本身设计过强**（要求 n ≥ 60 的**每一个**点都 ≤ 1 pp），
   比"收敛到 1 pp"强得多。按预注册如实判定为不稳健，
   同时在 §5 给出**事后（Level C）**的正确读法。
4. **对论文的净影响**：这一轮把结论从"我们测到一条标度律"削成
   "我们测到一条**方向稳健、数值条件依赖**的对比"——更弱、但更可信。

## 5. 事后重算（**Level C，只能写为线索**）

| 读法 | 结果 |
| --- | --- |
| S2 在 n = 80 时 SD ≤ 1 pp | **3/4**（N09 = 1.09） |
| S2 在 n = 96 时 SD ≤ 1 pp | **4/4**（0.00–0.93） |
| S2 单调下降 | **4/4** |
| S1 在 n ≥ 40 后不再下降（末点 ≤ n=40 的 1.2 倍） | **3/4** |

## 7. Limitation

1. 仍只有 **6 个物理轴承**；n 的增长在记录维度；
2. R = 100（低于主分析 150），N09 的 S1 在 n = 80/96 出现 SD = 0 的量化下限；
3. 测试集 24 条 → 分辨率 4.17 pp；
4. 单一试验台、单一检测器、单一分位；
5. R1/R2 的判定形式已按预注册如实报告，§5 的修正是事后分析。
