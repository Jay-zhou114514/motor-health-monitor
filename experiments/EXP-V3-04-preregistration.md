# EXP-V3-04 预注册：报告缺口审计（reporting-gap audit）

- 日期：2026-09-22
- 状态：**在运行之前冻结并提交**
- 目的：把"五点报告清单"从经验建议变成**有实证基础的测量**——量化已发表论文在
  "报告误报率"这件事上的缺口比例。

## 1. 问题

> 已发表的轴承/PHM 异常检测论文，在报告误报率相关关键信息时，缺失比例是多少？

## 2. 抽样框（先冻结，保证可复现）

| 项 | 规定 |
| --- | --- |
| 时间窗 | 2021-01-01 ~ 2026-08-31 |
| 检索源 | Scopus + IEEE Xplore（若不可得，退化为 OpenAlex + 期刊官网开放获取页，并在记录中声明） |
| 检索式 | `("bearing" OR "rolling element") AND ("anomaly detection" OR "fault detection" OR "condition monitoring" OR "one-class")`，限定标题/摘要 |
| 纳入条件 | ① 训练只用健康数据（或明确的一类方法）；② 报告了误报率或可换算的等价量；③ 使用至少一个公开轴承数据集；④ 可获取全文 |
| 排除条件 | 综述/评论；纯仿真；仅报告准确率而无误报口径；无法获取全文 |
| 抽样 | 若符合条件者 >30 篇：按**发表年份分层**随机抽 30 篇（种子 20260922）；≤30 篇则全取 |

## 3. 编码（五点清单，逐条二元 + "部分"）

| 编号 | 编码项 | 判为"已报告"的标准 |
| --- | --- | --- |
| R1 | 训练窗口数/记录数 | 给出训练集的窗口数或记录数（仅给"数据集规模"不算） |
| R2 | 重采样变异性的**≥2 个来源** | 至少报告划分组成与随机种子两类变异之一并给出数值 |
| R3 | 并列率（tie rate） | 当验证分辨率粗于目标误报水平时，报告并列或分辨率 |
| R4 | 区分"新增记录"与"重复采样" | 明确训练样本是否为同一批记录的重采样 |
| R5 | 独立单元数及其是否留出 | 给出物理单元（轴承/试验台）数量与是否整单元留出 |

编码规则：`1 = 明确报告`、`0.5 = 部分（如只给数量不给留出方式）`、`0 = 未报告`。
**双人独立编码 ≥20% 样本**，报告 Cohen's κ；分歧由第三人（或作者）裁决并记录。

## 4. 指标与判据

| 指标 | 定义 |
| --- | --- |
| P1 | 各 R1–R5 的"完整报告率"（编码 1 的比例）+ Wilson 95% CI |
| P2 | "全部 5 项都报告"的论文比例 |
| P3 | 缺口最大的两项（预期：R4 与 R5） |

**判据 H15**：至少 3 项的报告率 < 50%（即"缺口是系统性的"）；
**H16**：R5（独立单元数）的报告率 < R1（训练量）的报告率（即"更关键的元信息报得更少"）。

## 6. 限制（必须写入论文）

- 抽样框受检索源与全文可及性限制（付费墙会造成选择偏差）；
- 编码是人工判断，双人编码只能部分缓解；
- 结论只针对"报告的完整性"，**不评价论文质量或作者意图**。
