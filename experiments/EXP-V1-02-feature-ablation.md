## 1. 实验契约

| 项目 | 内容 |
| --- | --- |
| Hypothesis | 方法 B 的误报来自特征层面（而非阈值）；逐个/组合移除特征可以定位到具体特征 |
| Dataset | MathWorks 滚动轴承故障数据（8 个文件） |
| Train | `baseline_1`、`baseline_2`（仅正常数据） |
| Test | 其余 6 个文件（1 正常 + 3 外圈故障 + 2 内圈故障） |
| Method | 马氏距离，分位数固定 0.99；特征集逐步增减 |
| Metrics | Accuracy / Precision / Recall / F1 / FPR / FNR / 混淆计数 |
| Rule | 阈值只由训练正常数据决定；测试数据只用于评价 |

## 3. Observation（观察到什么）

1. 所有特征集的**召回率都是 1.000**，差异全部来自误报——检测故障从来不是难点。
2. 特征越多，误报越多：RMS only = 1，加入峭度或峰均比 = 2，加入谱质心 = 8，
   三个特征 = 3，四个特征 = 9。
3. RMS-only 的马氏阈值 2.0296 ≈ 2.03σ，与 EXP-V1-01 中 k = 2 出现 1 个误报
   的结果完全一致——两个独立实验互相验证。
4. 单变量分布几乎重合（偏移 < 0.7σ），但相关性结构差异极大，
   例如 rms–kurtosis 从 -0.065 变成 +0.511，crest_factor–centroid 从 -0.051 变成 +0.624。

## 4. Interpretation（如何解释）

1. 方法 B 的误报来自**联合分布（相关性结构）差异**，不是阈值，也不是单变量漂移。
2. 马氏距离用协方差矩阵的逆来度量距离；相关性一旦变化，
   正常样本在距离上会被显著"放大"，于是被判成异常。
3. 加入谱质心的退化最严重，因为它在 baseline_3 中与峰均比、峭度的相关性发生了反转。
4. 因此"误报多"不能靠调阈值或继续加特征解决；可行方向是增加/对齐正常数据、
   使用更稳健的协方差估计，或限制特征数量——但都需要先有误差分析证据。

## 5. Limitation（不能证明什么）

1. 训练只有 22 个正常窗口，4 维协方差估计本身不稳定（样本数/维度 ≈ 5.5）。
2. 只有 1 个正常测试文件，无法判断这种相关性差异是否具有普遍性。
3. 两个训练正常文件可能来自同一工况，不能代表所有正常状态。
4. 本实验不能证明"特征越多一定越差"，只能说明**在这份数据与这个划分上**如此。
