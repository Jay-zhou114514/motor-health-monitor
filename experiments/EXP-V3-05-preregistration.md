# EXP-V3-05 预注册：多分析者实验（many-analyst experiment）

- 日期：2026-09-22
- 状态：**在运行之前冻结并提交**
- 目的：把论文的核心主张——"分析者的选择影响报告结果"——从**推断**（用重采样代理）
  变成**直接观测**（多位同行在相同数据、相同目标下各自做出选择并报告结果）。

## 1. 问题

> 给同一批健康数据、同一目标（1% 误报率）与同一留出单元，**不同分析者报告出来的误报率差异有多大？**

## 2. 设计与材料（先冻结）

| 项 | 规定 |
| --- | --- |
| 参与者 | **5–10 人**（同行，具备基本 Python/信号处理能力），匿名编号 A1…A10 |
| 数据 | Paderborn 健康轴承：训练 = 5 颗轴承 × 1 工况（各 20 条记录）；测试 = 1 颗留出轴承（20 条记录） |
| 任务说明 | 两页 brief：只用健康数据拟合；阈值取训练分数的 1% 分位（等价 0.99 分位）；报告**测试单元上的误报率**；记录全部选择 |
| 必须提交 | ① 代码或 notebook；② 报告的误报率；③ **选择日志**（特征集、窗口长度/步长、检测器、预处理、并列处理方式） |
| 时限 | 每人 ≤3 小时；同一 brief、无额外指导（可在说明范围内提问，问答全员共享） |

**参照管线**（不告知参与者）：冻结的特征（rms/crest/kurtosis/centroid）、W-B 口径
（0.25 s/0.125 s）、iForest(200,0.5)、0.99 分位 → 参考值。

## 3. 指标与判据

| 指标 | 定义 |
| --- | --- |
| M1 | 报告误报率的**跨分析者 SD、极差、IQR**（主要指标） |
| M2 | 选择组合的分布（特征集 × 窗口 × 检测器 的取值频次） |
| M3 | 报告值落在 [0.5%, 2%]（名义 ±）的分析者比例 |
| M4 | 方差分解：选择差异 vs 实现差异（若每人提交多份实现） |

**判据 H17**：跨分析者 SD ≥ 5 pp（与 EXP-V1-10 重采样的 4.13 pp 同量级或更大）；
**H18**：至少 3 种不同的"选择组合"被使用；
**H19**：M3 < 0.5（多数分析者报告值偏离名义目标一个量级以上）。

## 4. 伦理与隐私

- 参与者知情同意；结果**匿名化**（A1…An，不记录姓名/单位）；
- 数据为公开数据集，不涉及敏感信息；
- 参与者可随时退出，退出者的部分提交不纳入分析（并记录退出人数）。

## 6. 限制（必须写入论文）

- 5–10 人样本量小，只能估计**量级**而非精确分布；
- 参与者来自同一圈子（同门/同领域），选择分布不代表全领域；
- brief 本身是一种约束（把自由度限定在"实现"层面），因此观测到的差异是**下界**。
