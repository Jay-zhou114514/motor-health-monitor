# EXP-V1-09 预注册：训练内超参协议

- 日期：2026-09-17
- 状态：**在运行实验之前冻结**（本文件先于任何 EXP-V1-09 结果提交）
- 依据：EXP-V1-08（现代单类方法误报最差）+ V1.5 计划；回应"是不是超参没调好"的质疑

## 1. 研究问题

> **在不使用测试集选择超参数的前提下，现代 one-class 方法（One-Class SVM / Isolation Forest）
> 经过训练内验证后，其跨批次误报表现是否能够达到预先设定的 ≤5% 水平？**

## 2. 关于判据 ≤5% 的定位（重要）

- ≤5% 是**预先设定的判定阈值**，用途是把"能否达到简单基线（3σ RMS ≈ 2.4%）的水平"
  **操作化**为一个可判定的问题；
- 它**不是** One-Class SVM / Isolation Forest "应当达到"的合理目标，
  **不得**被解释为对这些方法的性能期望或公平要求；
- 各批次文件数不同（IMS 1st = 12 个、2nd/4th = 6 个），且每个留出文件只有约 **7 个窗口**，
  因此**单折 FP rate 的分辨率约为 1/7 ≈ 14.3%**，批次均值分辨率约为 1/84 ≈ 1.2%（1st）
  与 1/42 ≈ 2.4%（2nd/4th）；
- 因此判定**只作用于批次均值**；单折数值仅作描述性报告。

## 3. 协议（嵌套 leave-one-file-out，全程不使用测试集选参）

对每个 IMS 批次、每个**外层**留出文件：

1. 外层训练集 = 该批次里其余文件；
2. **内层**：在训练集内部再做 leave-one-file-out —— 对每个候选超参组合，
   用内层训练文件拟合、在内层留出文件上计算 FP rate，取平均；
3. 选择**内层平均 FP rate 最低**的超参组合（并列时取更保守者：nu 更小 / 树更多）；
4. 用该超参在外层训练集上重新拟合，评估外层留出文件；
5. 汇总为该批次的**批次均值 FP rate**。

参考方法（无超参可调，作为对照）：A 3σ RMS 阈值、B 马氏距离。

## 4. 超参候选网格（预先定义，不得扩充）

| 方法 | 超参 | 候选值 |
| --- | --- | --- |
| One-Class SVM | `nu` | 0.001, 0.005, 0.01, 0.05, 0.1 |
| One-Class SVM | `gamma` | "scale", 0.1, 1.0, 10.0 |
| Isolation Forest | `n_estimators` | 100, 200 |
| Isolation Forest | `max_samples` | 0.5, 0.8, 1.0 |

（共 20 组 OC-SVM 组合、6 组 iForest 组合。）

## 5. 指标

1. **批次均值 FP rate**（主指标，用于判定）；
2. 单折 FP rate（描述性，附分辨率说明）；
3. 被选中的超参组合及其**折间稳定性**（不同折选到同一组合的比例）；
4. 计算耗时（拟合 + 超参搜索，用于"低成本"讨论）。

## 6. 预定义预测与判定

| 编号 | 预测 | 判定 |
| --- | --- | --- |
| P1 | 至少一种现代方法（C/D）在 **3 个 IMS 批次**上的批次均值 FP rate ≤5% | 支持 |
| P2 | 在 1–2 个批次上达到 ≤5% | 部分支持 |
| P3 | 0 个批次达到 ≤5% | 不支持 |
| P4（次要） | 训练内选出的超参在同批次不同折之间**不稳定**（同一组合被选比例 < 50%） | 成立 / 不成立 |

P4 的意义：若超参选择本身不稳定，则"通过调参达到目标"这一说法在该数据规模下不成立，
实测结果更像随机波动而不是可复现的调优。

## 7. 规则

1. 超参网格、内层选择准则、外层评估口径在本文件冻结；
2. **任何环节都不得使用外层留出文件（测试）来选择超参或阈值**；
3. 阈值仍统一取训练窗口分数的 99% 分位；
4. 失败结果保留；不做基于文件数的显著性声称；
5. 本文件先于结果提交。

## 8. 不可声称

- 不得把 ≤5% 写成"现代方法应有的水平"；
- 不宣称跨设备泛化（IMS 三批次同属一类试验台）；
- 不宣称统计显著性（独立单元仅 3 个批次）。
