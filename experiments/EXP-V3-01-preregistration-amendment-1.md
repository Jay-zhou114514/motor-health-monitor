# EXP-V3-01 修订 1：第一版仅覆盖 XJTU-SY 与 PRONOSTIA

- 日期：2026-09-21
- 状态：**在运行之前冻结并提交**
- 原预注册：`EXP-V3-01-preregistration.md`（2026-09-21 提交，commit 0a73bda）

## 修订内容

原预注册的数据集为 PRONOSTIA / XJTU-SY / Paderborn / IMS。实际实现的**第一版**
只覆盖 **XJTU-SY 与 PRONOSTIA**，原因：

1. 这两套数据集已有现成的特征缓存 `outputs/r2f_features.csv`（由 `runtofailure_data.py`
   生成，每颗轴承前 60 条记录的特征向量），可直接复用于 leave-one-unit-out，无需重算信号；
2. Paderborn 走另一条数据管线（`paderborn_data.py`，20 kHz、多工况），IMS 的单元是**批次**
   而非轴承——两者都需要单独的装载与单元定义核对；
3. 先把方法与判据在同类单元（轴承）上跑通，再按同一代码路径扩展到 Paderborn 与 IMS，
   避免在单元定义存在异质性的情况下混合汇报。

## 对判据的影响（不变）

- H1/H2/H3 与 M1–M4 的定义**完全不变**（见原预注册 §3–§4）；
- 原预注册要求"H1 在 ≥3/4 数据集上方向一致"。第一版可用的单元集合为：
  XJTU-SY 三个工况 + PRONOSTIA 三个载荷（共 6 个单元集合），因此第一版把该判据读作
  **"≥3/6 单元集合上方向一致"**；第二版（加入 Paderborn 与 IMS）再回到原口径
  （≥3/4 数据集），并在结果表中同时给出 6/6 与按数据集聚合的两种读数；
- 若第一版与第二版结论不一致，以**第二版为准**，并在实验记录中说明差异。

## 未变的部分

特征、检测器、阈值分位（0.99）、记录预算（20 条）、重复次数、随机种子来源（`zlib.crc32`）、
退化与饱和的处理规则、三层验证要求，全部沿用原预注册。

## 披露要求

本修订必须与原预注册一起出现在实验记录中；若第二版未能完成，论文中只允许按第一版的
单元集合陈述结论（6 个单元集合，而非四个数据集）。
