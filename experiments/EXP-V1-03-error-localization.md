## 1. 实验契约

| 项目 | 内容 |
| --- | --- |
| Question | 误报是否与正常文件内部的时间变化、以及多变量依赖结构变化有关？现有相关系数差异是真实差异还是小样本波动？ |
| Dataset | MathWorks 滚动轴承故障数据（8 个文件） |
| Train | `baseline_1`、`baseline_2`（仅正常数据，22 个窗口） |
| Test | 其余 6 个文件；误差定位聚焦唯一正常文件 `baseline_3`（11 个窗口） |
| Parts | A 误报时间定位；B 逐文件相关矩阵；C bootstrap 置信区间；D leave-one-feature-out；E 协方差条件数 |
| Rule | 阈值只由训练正常数据决定（马氏距离，分位数 0.99）；测试只用于评价 |

## 3. Observation（观察到什么）

1. 误报分散在整个记录时间上（9/11），不是集中在某个时间段；两个未误报窗口恰在阈值附近。
2. 误报窗口的距离主要由 RMS（59.1%）和谱质心（32.5%）贡献。
3. 删掉 RMS 或谱质心后误报从 9 降到 2~3；删掉峰均比或峭度几乎无改善（仍为 8~9）。
4. 四个关键相关性的 bootstrap 95% 置信区间在训练与测试之间**全部重叠**。
5. baseline_1 与 baseline_2 的相关性差异同样很大（如 rms–kurtosis：-0.438 vs +0.120）。
6. 四特征协方差条件数达 3.8×10⁹（训练）与 2.0×10¹⁰（baseline_3）；
   rms+centroid 同样病态，而 rms+kurtosis 只有 1.8 / 3.1。

## 4. Interpretation（如何解释）

1. 结论只能写到这个强度：

   > The observed false positives are consistent with a shift in the multivariate
   > dependency structure between training-normal and test-normal data, rather than
   > being explained by marginal mean/scale shifts alone.

   > 当前结果表明，观察到的误报与训练正常数据和测试正常数据之间的多变量依赖结构变化一致，
   > 而单变量均值/尺度漂移不足以解释该现象。

2. **但不能宣布"相关性导致误报"**：四个相关性的 bootstrap 置信区间全部重叠，
   说明观测到的相关系数差异无法与小样本随机波动区分（训练 n=22，测试 n=11）。
3. 一个证据更强的替代机制：**协方差矩阵严重病态（近共线特征 + 小样本）**。
   RMS 与谱质心高度相关（r ≈ −0.95），协方差接近奇异；求逆后微小偏差被放大成巨大距离。
   这与两个观测一致：条件数极高（10⁹ 量级），且删掉 RMS 或谱质心即可消除病态（误报 9 → 2~3）。
4. 证据强度：机制 3 目前比"相关性结构真的变了"更受数据支持，但同样需要更多正常数据才能确认。

## 5. Limitation（不能证明什么）

1. 训练 22 个窗口、测试正常仅 11 个窗口，置信区间很宽，统计功效不足。
2. 只有 1 个正常测试文件，无法判断该现象是否普遍。
3. 条件数与留一法支持"病态协方差"假说，但相关不等于因果，不能直接下结论。
4. 阈值敏感性扫描范围有限（EXP-V1-01：分位数 0.90~0.999，k = 2~4）。
