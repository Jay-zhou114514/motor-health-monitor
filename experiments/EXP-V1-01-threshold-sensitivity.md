## 1. 实验契约

| 项目 | 内容 |
| --- | --- |
| Hypothesis | 检测性能可能对报警阈值高度敏感；若敏感，"最优阈值"很可能只是碰巧选出来的 |
| Dataset | MathWorks 滚动轴承故障数据（8 个文件） |
| Train | `baseline_1`、`baseline_2`（仅正常数据，用于拟合模型和阈值） |
| Test | 其余 6 个文件：1 正常 + 3 外圈故障 + 2 内圈故障 |
| Method A | 3σ RMS 阈值，扫描 k = 2 / 2.5 / 3 / 3.5 / 4 |
| Method B | 马氏距离，扫描分位数 = 0.90 / 0.95 / 0.99 / 0.995 / 0.999 |
| Metrics | Accuracy / Precision / Recall / F1 / FPR / FNR / 混淆计数 |
| Rule | 所有阈值只由训练正常数据决定；测试数据只用于评价 |

## 3. Observation（观察到什么）

1. 方法 A 在 k = 2.5 到 4 之间结果完全相同（零误报、零漏报）；只有 k = 2 时出现 1 个误报。
2. 方法 B 的分位数从 0.90 提到 0.999，阈值从 2.59 升到 2.90，但所有指标完全不变（F1 = 0.873，FP = 9）。
3. 测试正常文件的所有窗口距离（2.374 ~ 4.737）都高于训练集得到的任何阈值（≤ 2.904）。

## 4. Interpretation（如何解释）

1. 方法 A 在这份数据上存在一个宽而稳的性能区间（k ∈ [2.5, 4]），说明它不依赖阈值精调。
2. 方法 B 的误报不是阈值问题：两个正常文件（baseline_1/2 与 baseline_3）之间存在分布差异，
   使测试正常样本整体落在训练正常分布之外；在这种情况下，调阈值无法解决误报。
3. 因此"方法 B 效果差"的正确解释是**特征/分布层面的问题**，而不是"参数没调好"。
   把它调参到看不出问题，反而是错误做法。

## 5. Limitation（不能证明什么）

1. 测试集只有 1 个正常文件，文件级误报率只能取 0 或 1，统计分辨率很低。
2. 阈值候选网格有限（每类 5 个取值），不能排除网格之间的细节差异。
3. 结论仅适用于当前数据集与当前特征集，不能外推到其他设备或工况。
