## 1. 设计

固定 iForest(200, 0.5)、阈值分位 q = 0.99、固定测试集（IMS 1st_test 前 2 文件，14 窗口）、
随机种子固定为 0（隔离种子来源）。扫描 n_train = {10, 20, 40, 80, 160, 320, 640}，
每格 R = 150；两个变体：V1 窗口级有放回抽窗、V2 以整文件为单位抽。

理想参照（阈值估计误差的经典 1/√n 律）：`SD_ideal(n) = sqrt(q(1−q)/n)`。

## 3. 预注册判据判定

| 判据 | 预期 | 实际 | 判定 |
| --- | --- | --- | --- |
| P1 | SD 随 n 单调下降 | Spearman = **−0.893**（p = 0.0068，两变体一致） | **成立** |
| P2 | 观测/理想落在 [0.5, 5] | 该比例仅 0.36；比值随 n 从 4.0 升到 12.9 | **不成立** |
| P3 | V2（记录级）系统性大于 V1 | 仅 29% 的规模满足 | **不成立（预期错误）** |

## 4. Observation

1. SD 确实随训练窗口数下降（P1 成立），但**下降极慢**：
   n 增大 64 倍（10 → 640），SD 只从 12.6 pp 降到约 4–5 pp（约 2.5 倍），
   远慢于 1/√n 所要求的 8 倍。
2. **理想 1/√n 律系统性低估噪声**：观测/理想比值随 n **从 4.0 增长到 12.9**，
   即样本越"多"，理想律错得越离谱。
3. **有效样本量崩塌**：n_eff/n 从 0.062（n = 10）降到 **0.006**（n = 640）。
   名义上 640 个训练窗口，其有效独立信息量约等于 **4–6 个窗口**。
4. SD 在 n ≥ 160 后**进入平台**（约 4–5 pp），不再随 n 明显下降。
5. **P3 失败**：记录级抽样在多数规模上并不比窗口级更差（小 n 时反而更好）。

## 5. Interpretation

1. **本实验最有价值的结果是负面的**：
   > 在"仅健康数据 + 训练分数分位阈值"的设置下，
   > **增加训练数据对降低误报率的报告不确定性几乎没有帮助**——
   > 至少远低于经典 1/√n 律给出的乐观预期。
2. **P3 失败的原因是我们自己的设计缺陷（必须记录）**：
   V2 在小 n 时实际拿到**更多窗口**（n = 10 时约 2 个文件 = 14 窗口），
   因此两个变体同时改变了"单元类型"与"实际窗口数"，不是干净的对照。
   该变体设计在后续实验中应改为"固定窗口数、只改变单元结构"。
3. **平台的来源需要谨慎**：训练集是从**固定池（70 个窗口）有放回**重采样得到的，
   因此 n = 640 时每棵树约 320 个样本中大量重复，
   模型并未获得真正的新信息。这一点同时**限制**了"平台"的解释：
   它说明的是"同一总体内增加样本量无法按 1/√n 改善"，**不能**直接说明
   "在现实中多采数据也没有用"。
4. **但正因为训练样本来自同一分布**，这条结果对理想律是一个**保守的下界反例**：
   在最有利的情形（数据分布完全已知、可以无限重采样）下，理想律已经高估了 4–13 倍；
   真实新数据的情形只会更差。
5. **对"样本量处方"的结论必须改写**：
   预注册中"ε = 1 pp → n ≥ 99 个窗口"这条处方**不可用**。
   按实测趋势外推，要在本设置下把误报率标准差压到 1 pp，
   需要的不是几十个窗口，而是**远大于本研究可获得的数据量**——
   或者换一种评价终点。

## 6. Limitation（不能证明什么）

1. 训练样本从固定池重采样，**不是新的独立测量**；结论限于"同一总体内"；
2. 测试集固定为 14 窗口（分辨率 7.14 pp），SD 存在量化下限，会高估平台高度；
3. 单一批次、单一试验台，检测器只有 iForest 一种（q = 0.99 一种分位）；
4. P3 的对照设计有缺陷（见 §5.2），**该变体结论不可引用**；
5. 不得写成"增加数据无用"；应写成"经典 1/√n 律在本设置下不成立"。

## 7. 对论文的含义（待审查）

- 这篇论文的主结果从"我们能给出样本量处方"变成
  **"在仅健康数据的轴承监测中，误报率的报告不确定性存在一个远高于经典估计的噪声下限；
  常规增加数据量无法按预期收敛"**；
- 这是一个**负面但有指导性**的结果，与 EXP-V1-10（并列率、split/seed 双重来源）互相支撑；
- 仍缺的一步：**跨体系是否同形**（V2-01 Paderborn），以及
  **在真实新增数据上的验证**（需要新采集，成本高，应列为 limitation 而非承诺）。
