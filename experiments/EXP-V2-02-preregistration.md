# EXP-V2-02 预注册：跨工况稳健性（S1 vs S2 对比是否在同试验台的其余工况上重现）

- 日期：2026-09-17

- 与主分析的关系：EXP-V2-01 预注册 §2 已声明"其余工况作为稳健性检查，不计入主判定"。
  本文件把该稳健性检查**具体化并冻结判据**，与主分析分开报告。

## 1. 问题

> EXP-V2-01 在 `N15_M07_F10` 上观察到的主结果
> （**名义 n 增长 ≠ 有效信息增长**）是否在同试验台的其余 3 个工况上重现？

## 2. 数据

Paderborn K001–K006，四个工况各 **120 条真实记录**（已解压核实）：

| 工况 | 转速 / 负载 / 径向力 | 记录数 |
| --- | --- | ---: |
| `N15_M07_F10` | 主分析（EXP-V2-01） | 120 |
| `N09_M07_F10` | 900 rpm | 120 |
| `N15_M01_F10` | 0.1 Nm | 120 |
| `N15_M07_F04` | 400 N | 120 |

## 3. 设计

**逐工况独立运行**，每个工况内部与 EXP-V2-01 完全同构：

- 固定测试集 = 该工况下每个轴承的 17–20 号记录（24 条）；
- 训练池 = 其余 96 条；
- S1 = 从训练池编号最小的 20 条中**有放回**抽 n 条；
- S2 = 从 96 条中**无放回**抽 n 条；
- n ∈ {10, 20, 40, 60, 80, 96}（去掉退化的 n = 5，理由见 EXP-V2-01 §2 注）；
- 检测器 iForest(200, 0.5)、阈值 q = 0.99、种子 0、固定测试集；
- **每格 R = 100**（低于主分析的 150，属计算规模选择，**先于运行声明**；判据均为方向性，不依赖高精度）。

**不做**：不合并四个工况、不跨工况训练（跨工况迁移是另一个问题，不在本实验范围）。

## 4. 预定义判据

| 编号 | 判据 | 含义 |
| --- | --- | --- |
| **R1** | 3 个工况中，n = 96 时 SD(S1) > SD(S2) | 主对比方向跨工况稳定 |
| **R2** | 3 个工况中，n ≥ 60 时 SD(S2) ≤ 1 pp | 真实新增记录能收敛到 1 pp 以内 |
| **R3** | 3 个工况中，S1 的 SD 在 n ≥ 40 后不再下降（末点 / n=40 点 ≤ 1.2） | S1 的饱和跨工况稳定 |
| **R4**（描述性） | 3 个工况的 efficiency(S2) 在 n = 80 时均 > 1 | 经典 1/√n 律在真实新增臂上过于保守 |

判定：

- **稳健**：R1 与 R2 同时成立（3/3 工况）；
- **部分稳健**：任一判据 2/3 成立；
- **不稳健**：任一判据 ≤ 1/3 成立 → 主结果必须限定为"单工况现象"，并在论文中降级。

## 5. 措辞纪律

- 即便全部成立，结论只能写 **"consistent across four operating conditions on one rig"**；
- **不得**写 cross-rig / generalization（跨试验台需另采数据或另一数据集）；
- 不得把四个工况合并成一个"大样本"。
