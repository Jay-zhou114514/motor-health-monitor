## 1. 修订 1 错在哪

修订 1 断言"振动通道 = `X.Raster = Mech_4kHz` → 4 kHz"。
**这是错的**：`X` 是**时间轴**结构，不是信号。

实际的 `.mat` 结构（经逐通道打印核实）：

```text
N15_M07_F10_K001_1
├── Info
├── X  (1×3)   ← 时间轴
│   X[0] raster = Mech_4kHz    len =  16,001
│   X[1] raster = HostService  len = 256,001
│   X[2] raster = Temp_1Hz     len =       5
├── Y  (1×7)   ← 测量通道
│   Y[0] force               Mech_4kHz    16,001
│   Y[1] phase_current_1     HostService 256,001
│   Y[2] phase_current_2     HostService 256,001
│   Y[3] speed               Mech_4kHz    16,001
│   Y[4] temp_2_bearing_module  Temp_1Hz       5
│   Y[5] torque              Mech_4kHz    16,001
│   Y[6] vibration_1         HostService 256,001   ← **振动信号在这里**
└── Description
```

## 2. 更正后的正确事实

| 项目 | 正确值 |
| --- | --- |
| 振动信号通道 | `Y['vibration_1']` |
| 振动采样率 | **64 kHz**（`HostService`，256,001 点 / 4 s） |
| 记录时长 | **4 s** |
| 力 / 转速 / 扭矩 | `Mech_4kHz`，16,001 点 / 4 s |
| 相电流 | `HostService`，256,001 点 / 4 s |

因此：**振动 = 64 kHz、4 秒/条记录**，与公开资料一致；修订 1 的"4 kHz"作废。

## 3. 两次连续错误的原因（必须记录）

1. 第一次：只看了 `X.Data` 的长度就推断"短片段"，没有读 `Raster` 与 `Time limit`；
2. 第二次：读了 `X.Raster` 却**误以为 `X` 是信号**，没有检查 `X`/`Y` 的维度
   （`X` 是 1×3 的时间轴，`Y` 是 1×7 的通道）；
3. **第二次是由特征健全性检查发现的**：按错误通道提取的特征在 120 条记录上标准差 ≈ 0
   （rms sd = 0.0003），这在物理上不可能，因此触发复查。

**流程教训（写入本预注册，供后续实验沿用）**：
> 任何新数据集在做正式实验之前，必须执行一次"特征健全性检查"：
> 提取全部记录的特征，确认其在样本间**有非退化变异**、且量级符合物理预期。
> 退化（标准差≈0）必须视为通道/单位错误的信号，而不是数据特性。

## 4. 需要重新决定的窗口约定（在跑正式实验前冻结）

修订 1 §3 选择"1 条记录 = 1 个特征向量（在整条 4 s 上计算）"。
该选择当时建立在"记录只有 0.25 s"的错误前提上。现在记录是 4 s @ 64 kHz，
需要重新在下面两个候选之间选定，并以特征健全性检查为依据：

| 候选 | 定义 | 优点 | 风险 |
| --- | --- | --- | --- |
| **W-A** | 整条 4 s 作为 1 个窗口 → 每记录 1 行 | 记录数 = 样本数，语义最干净 | 4 s 窗内的 crest/kurtosis 对冲击不敏感，特征可能退化 |
| **W-B** | 0.25 s / 0.125 s（与 IMS 冻结口径一致）→ 每记录 31 窗，**按记录取均值**后每记录 1 行 | 与 IMS 口径一致；特征有物理含义 | 引入一次聚合步骤，需在预注册中写清 |

**决定规则（先于运行）**：若 W-A 的特征在 120 条记录上出现退化（任一特征标准差 < 1% 相对量级），
则采用 W-B；否则采用 W-A。该规则的具体执行结果记录在修订 3 中。
