## 3. Observation（观察到什么）

1. **H1 的复现是折依赖的**：问题组的膨胀与 9/11 误报只在 F1 出现；
   F2/F3 中问题组的表现与其他两组接近（膨胀比 < 0.8）。
2. 冻结指标 s(x) 在问题组内部与膨胀比同向（ρ = 1.0，3 个折），
   但"三组之间的 s 排序 = 膨胀比排序"只在 1/3 折成立。
3. P1 虽然形式上成立（2/3 折），但 F2 的差距极小（0.734 vs 0.723），
   属于统计上没有意义的差距。
4. **H2 的复现更稳**：C3（Ledoit–Wolf 解析式）与 C5（条件数 ≤ 100 的最小 δ）
   在三折中都选出 δ > 0，并且都把问题组的膨胀比降到 < 1、同时不增加对照组误报。
5. 基于似然的两个准则（C2 窗口级 LOO、C4 文件级 LOO）几乎都选 δ ≈ 0，
   无法发现该问题；简单几何准则 C5 反而稳定有效。
6. 不同准则选出的 δ 差异很大（平均极差 0.433），说明"选择准则"确实是关键变量。

## 4. Interpretation（初步理解，待审查）

1. **H1（几何归因）：从"部分支持"下调为"复现性不足"。**
   冻结指标只在 F1 显示问题组膨胀；F2/F3 不支持"该几何是普遍问题"的说法。
   更可能的解释是：**F1 的问题来自 baseline_3 与另外两个正常文件之间的特定差异**，
   而不是 RMS+centroid 几何本身的普遍性质。
2. **H2（正则化）：获得跨折支持。**
   两个 training-only 准则在三折中稳定选出 δ>0，并降低膨胀比。
   其中 C5（条件数 ≤ 100）简单、可解释、可在训练集上计算，是目前最有实用价值的候选准则。
3. 但要注意：H2 的效果在 F2/F3 上"锦上添花"（本来膨胀比 <1，无 FP 问题），
   真正的价值集中在 F1 这一折——即**修复只在问题出现时才有意义**。
4. 证据等级：H1 由 Level B 下调为 **Level C（复现性不足）**；
   H2 提升为 **Level B+（三折一致，但仍为单数据集）**。

## 5. Limitation（风险审查要点）

1. 只有 3 个正常文件、3 个折，无法构成强泛化证据。
2. F2/F3 中问题组没有出现膨胀，说明原现象的适用边界尚未界定。
3. F1 的特殊性（baseline_3 与另外两个文件的差异）尚未被独立刻画。
4. 冻结指标 s(x) 的跨组排序能力在本实验中未通过（P2 不成立）。
5. 五个准则中 C1/C2/C4 在 F1 完全无效，说明"用似然选 δ"在本任务上不可靠。
