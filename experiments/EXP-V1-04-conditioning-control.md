## 1. 实验契约

| 项目 | 内容 |
| --- | --- |
| Hypothesis | 若误报部分来自协方差病态，则条件数更低的特征组合应当（预测 1）误报更少，（预测 2）阈值估计更稳定 |
| Control | 数据集、train/test 划分、窗口参数、检测方法（马氏距离）、协方差估计（经验协方差）、分位数（0.99）、评价协议全部固定，只改变特征集 |
| Dataset | MathWorks 轴承数据 |
| Train | `baseline_1` + `baseline_2`（22 个正常窗口） |
| Test | 1 正常 + 3 外圈 + 2 内圈（42 个窗口，31 个故障） |
| Metrics | condition number、threshold、threshold CV（留一训练窗口重拟合）、FP、TN、precision、recall、F1、FPR、距离分布、距离膨胀比 |
| Judgement | Spearman(log10 condition number, FP) 与 Spearman(log10 condition number, threshold CV) |

## 3. Observation（观察到什么）

1. 误报集中在**包含 RMS 与谱质心的组合**：8、9、8、9；其余 7 个特征集误报为 1~3。
2. 条件数与误报的描述性秩相关为正（ρ = 0.745），但同维度内**不单调**：
   条件数从 1.79 升到 1.98 × 10⁸（跨 8 个数量级）时误报仍是 1~2，
   只有含 RMS + centroid（≈ 3.55 × 10⁹）时才跳到 8。
3. 阈值稳定性（留一训练窗口重拟合的变异系数）在所有特征集都很接近（0.023~0.053），
   与条件数无显著关系（ρ = 0.264，p = 0.43）。
4. 距离膨胀比只有含 RMS + centroid 的四个特征集大于 1（1.35~1.50），
   其余全部小于 0.8；膨胀比 > 1 意味着测试正常窗口的距离中位数本身就超过阈值。

## 4. Interpretation（初步理解，待结果审查）

1. **预测 1：部分支持。** 条件数与误报同向，但条件数**既不充分也不必要**：
   crest + centroid（4.24 × 10⁵）与 kurtosis + centroid（1.98 × 10⁸）同样病态，
   却没有产生误报。
2. **预测 2：不支持。** 阈值估计的稳定性不是区分因素；
   不稳定的不是"阈值"，而是"测试正常样本的距离"（膨胀比 > 1）。
3. **精炼后的机制表述**：当前结果提示，误报可能与 RMS–谱质心近共线结构
   及其对应低方差方向与正常文件间分布差异的对齐有关。
   该表述属**合理假说、尚未证实**（只有 1 个正常测试文件、11 个窗口，
   且"方向一致性"来自 V1-04 的事后观察）。
4. 证据等级：**Level B**（受控实验支持，但受样本量与特征集非独立性限制）。

## 5. Limitation（风险审查要点）

1. 11 个特征集是嵌套结构、彼此非独立，Spearman 的 p 值只能作描述性使用；
   若按 11 次比较做 Bonferroni 校正，p = 0.0085 × 11 > 0.05，不再显著。
2. 测试正常只有 1 个文件（11 个窗口），FPR 分辨率只有 1/11，FP 只能取整数。
3. 窗口 50% 重叠，有效样本量小于窗口数。
4. "膨胀比 > 1 对应含 RMS + centroid" 属于事后观察，需要预先定义的新实验验证。
5. 经验协方差在 n = 22 下的估计误差没有被单独量化。

## 6. 未决问题（供结果审查与 V1.2 讨论）

1. 用正则化/收缩协方差（λI 或 Ledoit–Wolf）替换经验协方差后，
   含 RMS + centroid 的组合能否降低膨胀比与误报？（可检验预测：膨胀比下降）
2. 是哪一个特征方向（协方差最小特征值对应的方向）在放大距离？
   能否用特征分解把"膨胀"定量归因到具体方向？
3. 更换/增加正常测试文件后，该现象是否仍然出现？
   目前只有 1 个正常测试文件，无法判断普遍性。

## 7. 最终审查结论（项目负责人，2026-09-15）

| 项目判定 | 结论 |
| --- | --- |
| 条件数 ↑ → FP ↑ | 部分支持，但不能作为主机制 |
| 条件数 ↑ → 阈值不稳 | 目前不支持 |
| RMS + 谱质心存在特殊问题 | 有较强实验线索 |
| "低方差方向导致距离膨胀" | 合理假说，尚未证实 |
| 经验协方差估计误差是重要因素 | 合理，但尚未单独验证 |
| A 收缩协方差 | 应该做 |
| B 方向归因 | 必须做 |
| C 稳健性扩展 | 暂时不要做 |

主线收缩为：V1-04（条件数本身不是充分解释）→ V1-05（是否是特定低方差方向 + 分布差异造成距离膨胀？）
→ 若支持则检验正则化能否修复 / 若不支持则推翻该机制重新定位。

V1-05 定位：**机制验证优先、修复验证并行**；不是为寻找提高 F1 的方法。
