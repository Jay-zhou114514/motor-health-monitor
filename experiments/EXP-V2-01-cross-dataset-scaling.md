## 1. 设计（按预注册）

固定测试集 = 每个轴承的 17–20 号记录（24 条，覆盖 6 个轴承）；训练池 = 96 条。
两臂在同一组 n 上对照：

| 臂 | n 增长来自 |
| --- | --- |
| **S1 重采样** | 从固定 20 条子集中**有放回**抽 n 条 |
| **S2 真实新增** | 从 96 条训练池中**无放回**抽 n 条（每格 n 条**互不相同**的真实记录） |

检测器 iForest(200, 0.5)、阈值 q = 0.99、随机种子 0、固定测试集；每格 R = 150。

## 3. 预注册判据的实际判定

| 判据 | 实际 | 形式判定 |
| --- | --- | --- |
| P1（S2 的 n_eff 持续增长） | 有限格（n = 10…80）为 1.89 → 4.49 → 22.5 → 100.4 → 430.6，**严格单调**；但含 n = 5 / n = 96 两个退化格后，比例与 Spearman 无法计算 | **形式不成立（判定实现缺陷）** |
| P2（S1 的 n_eff 饱和） | 末点/首点 = 0.00，rho = −0.321 | **成立** |
| P3（同 n 下 S2 效率更高） | 6/7 | **成立** |
| P4（S2 斜率更接近 −0.5） | 因退化格导致 log-log 回归 nan | **不成立（无法判定）** |

**必须如实记录**：P1 与 P4 的失败**来自判据实现**（把 n_eff = ∞ 的退化格纳入统计、并用比值做首末比较），
**不是来自数据**。按预注册规则，P1 形式不成立时应执行"饱和是固定总体假象"的分支——
而这一点与数据方向**一致**（见 §4.1）。

## 4. Observation

1. **两臂的差距是压倒性的**：在**相同**名义 n 下，
   S1（同一 20 条记录反复重采样）的 SD 停在 **16–18 pp** 并与 n 无关；
   S2（真实新增记录）的 SD 从 7.24 pp 单调降到 **0.00 pp**。
   最尖锐的对比在 n = 96：**SD 18.04 pp（S1） vs 0.00 pp（S2）**。
2. S1 的 n_eff 在 0.18–0.38 之间**不随 n 增长**；S2 的 n_eff 增长到 430 以上，
   **efficiency 甚至超过 1**（n = 80 时 5.38）。
3. 两臂的**均值误报率**也不同：S1 随 n 升高到约 20%，
   S2 降到 0%——即 S1 的"更多重复"不只是增大方差，还系统性地**抬高**误报水平。
4. 各轴承之间存在系统差异（训练池 rms：K001 0.403 vs K004 0.171），
   因此"真实新增记录"确实在增加**新的单元信息**。

## 5. Interpretation

1. **核心命题成立**：
   > **在仅用健康数据的轴承异常检测中，名义样本量的增长不等价于有效信息量的增长。**
   只有"新增**不同的真实记录**"才带来信息；在同一有限总体内增加重复采样次数，
   有效信息量**不增长**（n_eff 停在 0.2–0.4），误报率的估计不确定性**不下降**。
2. **EXP-V1-11 的"饱和"得到解释**：那是"固定 70 窗池 + 有放回重采样"的产物，
   **不是**一般性规律。按预注册的分支规则，EXP-V1-11 的相关表述已在本实验后降级
   （见 §6 的更正动作）。
3. **经典 1/√n 律在两个方向上都不成立**：
   S1 上它过于乐观（观测/理想达 10–18 倍），S2 上它过于保守（efficiency > 1）。
   因此该公式在"仅健康数据 + 阈值估计"场景中**不能作为处方**。
4. **对工程实践的直接含义**：
   > 想知道误报率的稳定性，不能靠"把同一条记录多采样几次"；
   > 必须**增加不同的真实记录**。在 Paderborn 上，约 **60 条真实不同记录**就能把
   > 误报率标准差压到 1 个百分点以内（IMS 规模的 5 倍）。
   该数量**只在本设置下成立**，跨体系迁移需 V2 后续检验。
5. 与 EXP-V1-10 的关系：V1-10 发现"同一批次内的划分/种子波动大"，
   本实验指出该波动的**可消除性取决于新增的是记录还是重复**——
   这解释了为什么在 IMS（12 条记录）上无论怎么重采样都到不了稳定估计。

## 7. Limitation（不能证明什么）

1. **只有 6 个物理轴承**：S2 的 n 增长发生在"记录"维度，
   轴承维度仍只有 6 个 → 不得声称"需要 60 个轴承"；
2. 单一工况（`N15_M07_F10`）；其余 3 个工况未纳入（未解压），稳健性检查待补；
3. 单一试验台、单一检测器（iForest 200/0.5）、单一分位（q = 0.99）；
4. 测试集 24 条 → 分辨率 4.17 pp，S2 的 n = 96 落在 0 误报（SD = 0），
   这是**量化下限**而非"完美无波动"；
5. **跨体系比较**只能比 efficiency 与缩放趋势，不得比 SD 绝对值
   （IMS 20 kHz / 1.024 s vs Paderborn 64 kHz / 4 s）；
6. P1 / P4 的判定实现有缺陷（§3），修正后的结果属**事后重算（Level C）**，
   只能作为线索写入，不得作为预注册结论引用。
