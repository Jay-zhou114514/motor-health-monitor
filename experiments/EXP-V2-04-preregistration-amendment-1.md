# EXP-V2-04 预注册修订 1：升级为**双数据集**（XJTU-SY + PRONOSTIA）

- 日期：2026-09-18
- 状态：**在运行之前提交**
- 触发：项目负责人指出——"增加数据"的定位应从**证明机制**升级为
  **验证评价不确定性是否跨设备、跨数据集存在**。

## 1. 定位升级（本修订的核心）

| | 原定位 | 修订后 |
| --- | --- | --- |
| 目标 | 证明"健康阶段定义不确定"这一机制 | **验证评价不确定性是否跨设备、跨数据集存在** |
| 若结果不利 | 白做 | **"不存在"同样是结论**：它为现象的适用范围划出边界 |
| 证据形态 | 单数据集 | **两个独立试验台 / 两个团队 / 两套采样制度** |

**必须理解的一点**：Paderborn 与 IMS 都是**设计好的健康轴承**，不存在"健康阶段"问题；
只有 run-to-failure 数据才需要人去发明健康阶段。
因此**这条主张的可辩护性完全取决于能否在第二组 run-to-failure 数据上复现**。
这正是本修订把 PRONOSTIA 纳入同一预注册、而非留作期刊扩展的原因。

## 2. PRONOSTIA 已核实的事实（官方挑战说明 PDF，11 页，已通读）

| 项 | 官方内容 |
| --- | --- |
| 轴承数 | **17 颗**（6 颗 learning + 11 颗 test）；3 种负载（工况） |
| 采样 | 加速度 **25.6 kHz**；每次 **0.1 s（2560 点）**；**每 10 s 一条** |
| 温度 | 10 Hz，每分钟 600 点 |
| 寿命 | 官方原话：**1 小时至 7 小时**，跨度极大 |
| 退化性质 | 原话：对应 "**normally degraded** bearings"——**缺陷不是预先植入的**，是自然退化；每颗退化轴承几乎含各类缺陷（球/内圈/外圈/保持架） |
| 退化来源 | 挑战赛**刻意不告知**（轴承类型、缺陷类型均未知） |
| 退化起始时刻 | **官方未提供**（与 XJTU-SY 相同） |
| 平台 | PRONOSTIA（FEMTO-ST）；主办：IEEE Reliability Society + FEMTO-ST |

**对先前说法的更正（必须记录）**：
本项目此前曾写下"PRONOSTIA 有若干**并非轴承退化导致**的失效样本，须显式排除或作敏感性分析"。
**该说法在官方文档中没有依据**。官方反而强调缺陷是自然退化、且每颗轴承含多类缺陷。
因此本修订规定：**PRONOSTIA 上不做任何 ad-hoc 排除**，一律套用同一条冻结规则。
（凡"传闻式排除"都不予采用；这是本次自审的又一条教训。）

## 4. 冻结规则：两数据集完全相同

```text
H = clip( max(20, 0.10 × N), 下限 20, 上限 60 )      纳入要求：H / N ≤ 0.25
```

**两数据集的执行结果（本次即用实测 N 计算，不跨数据集合并）**：

| 数据集 | 轴承数 | 通过纳入门槛 | 卡在哪一侧 |
| --- | ---: | ---: | --- |
| XJTU-SY | 15 | **13** | **卡下限**（Bearing2_4 仅 42 条、Bearing1_5 仅 52 条） |
| PRONOSTIA | 17 | **17**（待脚本复核） | **卡上限**（最长 2873 条，10% = 287 → 封顶 60） |

预期中的关键观察：**同一个自由参数在两组数据上以相反方式起作用**。

## 5. 其它统一项

- 通道：XJTU-SY 用**水平**（第 1 列）；PRONOSTIA 用**水平**（第 5 列，`acc_*.csv` 的 6 列中第 5 列）；
  另一通道作稳健性检查；
- 1 条记录 = 1 个特征向量（XJTU-SY：整条 1.28 s；PRONOSTIA：整条 0.1 s）；
- **PRONOSTIA 的 0.1 s 记录较短**，频谱类特征（`centroid_hz`）的可靠性低于 XJTU-SY——
  这一点必须写进限制，且**不得**据此比较两侧的绝对误报率；
- 检测器 iForest(200, 0.5)、阈值 = 训练分数 0.99 分位、种子 0、R = 100（敏感性格 R = 60）；
- bearing-level holdout：**XJTU-SY 13 折**、**PRONOSTIA 17 折**（逐颗留出）。

## 6. 判据（每数据集**分别**判定，不合并）

| 编号 | 判据 |
| --- | --- |
| X1 | 5 组健康阶段规则下，S3(k_max) 的 SD 极差 > 2 pp（k_max = XJTU-SY 12 / PRONOSTIA 16） |
| X2 | ≥ 各数据集的 85% 折数，S3 的 SD 随 k 下降 |
| X3 | ≥ 85% 折数，SD(k_max) < SD(k=1) |
| X4 | ≥ 85% 折数，S2 的 SD 随 n 下降 |
| **X6（跨数据集，新增）** | **X1 在两个数据集上同时成立** → 支持"跨设备、跨数据集的评价不确定性" |

判定：

- **X6 成立**：主张升级为跨数据集的评价不确定性，写进摘要；
- **X6 不成立（单侧成立或都不成立）**：**如实写成"该不确定性未能在两个体系上同时复现"**，
  并按项目既有规则降级（这正是本修订把定位改成"验证是否存在"的价值所在）。

## 7. 措辞纪律（补充）

1. **禁止**跨数据集比较绝对误报率（采样制度不同：1.28 s/1 min vs 0.1 s/10 s）；
2. **禁止**声称"官方健康阶段是错的"——官方未给出 onset，我们只是公开我们的定义并量化其影响；
3. 两个数据集**都是同一类 run-to-failure 试验**，不得写成"跨设备泛化"到任意工业场景；
4. 不得把 PRONOSTIA 的 learning/test 划分当作我们的 train/test——我们一律用 **leave-one-bearing-out**。

## 8. 运行规模

| 数据集 | 折数 | 规模 | 预估 |
| --- | ---: | --- | ---: |
| XJTU-SY | 13 | S2 4 格 × 100 + S3 5 格 × 100 | ≈ 21 min |
| PRONOSTIA | 17 | 同上 | ≈ 27 min |
| 健康阶段敏感性 | 2 × 5 组 × 3 格 × 60 | ×2 数据集 | ≈ 22 min |

合计约 **70–80 分钟**。若超时按既有惯例另开修订调规模，**不改判据**。
