# EXP-V1-11 预注册：阈值估计噪声下限与样本量处方

- 日期：2026-09-17
- 状态：**在运行之前冻结并提交**
- 定位：论文 Conference Track 的核心图与处方来源；不是新方法，不追求 F1

## 1. 研究问题

> 在"仅用健康数据训练 + 阈值取训练分数分位数"的检测器里，
> **报告的误报率精度**由什么决定？能不能给出一条可用的样本量处方？

## 2. 已知起点（来自 EXP-V1-10 与方差分解）

- 固定测试集时，报告的误报率仍有 SD ≈ 4–5 个百分点；
- 该波动**同时**来自训练集组成与算法随机性，两者量级相当（比值 1.18）；
- 机制假设：阈值是 n_train 个训练分数的 99% 分位，**阈值自身的估计噪声大于测试分数在阈值附近的间距**，
  导致"越过阈值的窗口个数"接近掷硬币。

本实验检验这条机制，并把它变成标度律。

## 3. 设计

**固定**：检测器 = iForest(200, 0.5)；阈值分位 q = 0.99；数据 = IMS 1st_test（12 个健康文件、84 个窗口）；
固定测试集 = 前 2 个文件（14 窗口）；随机种子固定为 0（隔离"种子"这一来源，因为它已由方差分解处理）。

**扫描**：n_train ∈ {10, 20, 40, 80, 160, 320, 640} 个训练窗口。

**两个变体**（用于区分"名义样本量"与"有效样本量"）：

| 变体 | 训练集构造 | 检验什么 |
| --- | --- | --- |
| V1 窗口级 | 从池化窗口中**有放回**抽 n_train 个窗口 | 理想情况：是否服从 1/n 标度律 |
| V2 记录级 | 以**整文件**为单位抽（每个文件 7 窗口），凑到 ≥ n_train | 保留文件内相关性，检验有效样本量 |

每个 (变体, n_train) 重复 R = 150 次，记录：阈值、固定测试集上的误报率、连续指标（测试分数的训练分位均值）。

## 4. 参照与指标

**理想解析下限**（阈值估计误差的经典结果，q = 0.99）：

```text
SD_ideal(n) = sqrt(q * (1 - q) / n)
```

**关键量**：

```text
有效样本量 n_eff = q * (1 - q) / SD_observed^2
低效系数     = n_eff / n_train      （越小于 1，说明真实数据比理想独立情形差多少）
```

**处方**（由 SD_ideal 反解，作为"理想情况下"的下界，须与实测对照后决定是否可用）：

```text
要达到 SD ≤ ε（以概率单位计），需要 n_train ≥ q * (1 - q) / ε^2
ε = 0.01 → n ≥ 99 ；ε = 0.02 → n ≥ 25 ；ε = 0.05 → n ≥ 4
```

## 5. 预定义判据

| 编号 | 判据 |
| --- | --- |
| P1 | 实测 SD 随 n_train 单调下降（Spearman(n_train, SD) < 0，两种变体均成立） |
| P2 | 实测 SD 与 SD_ideal 同量级：比值 SD_obs / SD_ideal 落在 [0.5, 5] 内 |
| P3 | **V2（记录级）的 SD 系统性大于 V1（窗口级）**，即文件内相关性使有效样本量低于名义样本量 |
| P4 | 由 V1 标度律外推得到的"ε = 1 个百分点所需 n_train"，与 SD_ideal 给出的 99 相差不超过一个数量级 |

判定：

- **支持**：P1 与 P3 成立 → 机制成立，且"有效样本量低于名义样本量"这一 PHM 特性成立；
- **部分支持**：仅 P1 成立；
- **不支持**：P1 不成立 → 机制假设被否证，须回到 EXP-V1-10 记录更正。

## 6. 限制（预先声明）

1. V1 变体的窗口是**有放回重采样**，不是新的独立测量；它检验的是标度律，不是"多采数据就一定更好"；
2. 测试集固定为 14 个窗口 → 本实验**只测量阈值来源的波动**，不测量测试集来源；
3. 单一批次、单一试验台；跨体系是否同形必须留给 V2-01；
4. 处方只在"阈值 = 训练分数分位数"这一类检测器上成立，不得外推到有监督分类；
5. 不声称"解决数据不足"，只声称"量化了稳定误报估计所需的健康样本量"。
