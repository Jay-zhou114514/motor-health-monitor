# EXP-V1-08 预注册：单类检测器基线对比

- 日期：2026-09-17
- 状态：**在运行实验之前冻结**（本文件先于任何 EXP-V1-08 结果提交）
- 依据：文献综述 v1 的增量边界（Vieira 2026 与 Knap 2026 均面向**有标签分类**；
  `unsupervised / one-class / anomaly detection / statistical power` 在其全文 0 命中）

## 1. 研究问题

> 在**只有健康数据可训练**的低成本监测场景下，简单统计检测器与"现代"单类机器学习基线相比，
> 在**记录级、泄漏安全**的评价协议下表现如何？这种对比在不同批次间稳定吗？

## 2. 被比较的检测器（全部只用健康（正常）窗口训练）

| 代号 | 方法 | 特征 | 说明 |
| --- | --- | --- | --- |
| A | 3σ RMS 阈值 | rms | 经典基线（单特征） |
| B | 马氏距离 | rms, crest_factor, kurtosis, centroid_hz | 经典多变量基线 |
| C | One-Class SVM（RBF） | 同上（按训练集标准化） | 现代单类基线 |
| D | Isolation Forest | 同上（按训练集标准化） | 现代单类基线 |

所有方法的报警阈值统一取**训练窗口分数的 99% 分位**（只用训练数据确定）。

## 3. 数据与协议

| 数据集 | 用途 | 文件 |
| --- | --- | --- |
| IMS 1st / 2nd / 4th | **误报评价**（无故障标签，只看健康记录） | 12 / 6 / 6 个健康文件 |
| MFPT（MathWorks 子集） | **判别力评价**（正常 vs 故障） | 3 个正常 + 5 个故障文件 |

- IMS：批次内 leave-one-file-out；窗口 0.25 s / 步长 0.125 s（沿用修订 1）。
- MFPT：训练用 2 个正常文件，测试用留出的 1 个正常文件 + 全部 5 个故障文件；
  窗口 1.0 s / 步长 0.5 s。
- 标准化（C/D 需要）：只用训练窗口的均值/标准差。
- **独立单元 = 试验批次**（沿用修订 2）；不做基于文件数的显著性检验。

## 4. 指标

1. **误报率（FP rate）**：留出健康文件中被报警的窗口比例（IMS 与 MFPT 均报告）；
2. **判别力（仅 MFPT）**：AUROC、在 **10% 误报预算**下的召回率、F1；
3. **稳定性**：同一方法在不同批次/折之间的 FP rate 离散程度；
4. 记录条件数与计算耗时（用于"低成本"讨论）。

## 5. 预定义预测与判定

| 编号 | 预测 | 判定 |
| --- | --- | --- |
| P1 | 在 IMS 健康数据上，C/D 的 FP rate ≤ A/B（现代单类方法误报更少） | 成立 / 部分成立 / 不成立 |
| P2 | 在 MFPT 上，10% 误报预算下 C/D 的召回率 ≥ A/B | 成立 / 部分成立 / 不成立 |
| P3 | 不存在"在所有数据集上同时误报最低且召回最高"的单一方法（方法优劣依赖数据） | 成立 / 不成立 |

总体判定：

- **支持**：P1 与 P2 均成立；
- **部分支持**：仅其一成立；
- **不支持**：均不成立；
- 若 P3 成立 → 支持"没有普适最优方法，必须报告评价条件与功效"的论点。

## 6. 规则

1. 阈值、特征、标准化方式、折设计在本文件冻结，运行后不得修改；
2. 训练只用健康窗口；测试文件只用于评价；
3. 失败结果保留；
4. 不做基于文件数（把文件当独立样本）的显著性声称；
5. 本文件先于结果提交。

## 7. 不可声称

- 不宣称"我们的方法优于深度学习"（本轮不含深度模型）；
- 不宣称跨设备泛化（IMS 三个批次同属一类试验台）；
- 不宣称统计显著性（独立单元仅 3 个批次）。
