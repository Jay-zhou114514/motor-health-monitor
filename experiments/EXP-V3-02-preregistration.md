# EXP-V3-02 预注册：报告误报率的"信任判定器"（trust diagnostic）

- 日期：2026-09-22
- 状态：**在运行之前冻结并提交**
- 前置：`EXP-V3-01-unit-calibration.md`（三次受控否定：ULTC、部分池化、大样本部分池化）
- 设计定位：**元分析（meta-analysis）**——不产生新实验数据，只使用已归档的单元级结果，
  因此不需要新硬件、新数据集，也不会与既有结论冲突。

## 1. 要回答的问题

> 给定**独立单元数 $n$** 与**每单元记录数 $m$**，一个报告的误报率是否值得被引用？

即：把"报告率的可信度"变成 $n$、$m$ 的函数，并给出可执行的判定准则。

## 2. 数据来源（全部为已有归档产物）

| 来源 | 单元集合数 | 单元类型 | 关键列 |
| --- | --- | --- | --- |
| `EXP-V2-03-summary.csv` | 2（within / holdout） | 轴承 | `mean_fp`, `sd_fp`, `n_train` |

**纳入规则（先冻结）**：只纳入同时给出"单元数"与"跨单元 SD（pp）"的单元集合；
退化格（SD = 0 或饱和）单独标记，不参与拟合但在结果表中列出。

## 3. 模型（先冻结函数形式，避免事后挑形式）

主模型（幂律 + 下限）：

$$\mathrm{SD}(n) = a\,n^{-\gamma} + c$$

备选模型（仅作敏感性，不用于判定）：$\mathrm{SD}(n) = a/\sqrt{n} + c$（经典 $n^{-1/2}$ 律）
与 $\mathrm{SD}(n) = c$（常数模型）。

参数由**所有单元集合**拟合（$a>0$、$\gamma>0$、$c\ge 0$）；拟合在同一权重下进行
（每单元集合等权，避免单元数多的集合支配）。

## 4. 判据（先冻结）

| 编号 | 判据 | 判定 |
| --- | --- | --- |
| **H7** | 幂律模型的指数 $\gamma$ 的 bootstrap 95% CI 不含 0（即 SD 确实随单元数下降） | 支持 / 不支持 |
| **H8** | **留一单元集合交叉验证**（LOO-CV）下，主模型预测留出集合 SD 的平均绝对误差 ≤ 8 pp | 支持 / 部分 / 不支持 |
| **H9** | 主模型的 LOO-CV 预测误差优于常数模型（"SD 与 $n$ 无关"） | 支持 / 不支持 |

**判定用途**：若 H7 与 H9 成立，则"信任判定器"可作为论文的方法贡献；
若 H7 不成立（SD 不随 $n$ 下降），则必须报告"在现有数据范围内，单元数增加并未系统降低
跨单元 SD"，并撤回判定器的"可预测"主张，只保留描述性结论。

## 5. 判定器的形式（先冻结，供论文使用）

由主模型导出**设计表**：

$$n_{\min}(\tau) = \min\{n : \widehat{\mathrm{SD}}(n) \le \tau\}$$

给定目标可信度阈值 $\tau$（论文中报三个：$\tau = 2$ pp、5 pp、10 pp），输出所需的最少独立单元数。
若 $\widehat{\mathrm{SD}}(n)$ 在数据范围内始终 $>\tau$，则如实报告"在现有单元数范围内
无法达到该可信度"——**这是允许且预期的一种结论**。

## 6. 统计与不确定性

- 参数 bootstrap：对单元集合重采样 10,000 次（固定种子 20260922），给出 $a,\gamma,c$ 与
  $\widehat{\mathrm{SD}}(n)$ 的 95% 区间；
- 预测误差用 LOO-CV（每次留出一个单元集合，用其余拟合后预测留出者）；
- 多重比较：对三个模型做 Holm 校正后的比较，声明 H7–H9 为预注册判据、其余为探索性。

## 7. 验证（元分析版本的三层）

- **L1**：纳入集合的清单可枚举（每个来源 → 行列 → 数值）；无 NaN；单元集合计数与来源一致；
- **L2**：用另一条代码路径（独立实现的最小二乘/网格搜索）复算 $a,\gamma,c$ 与 LOO-CV 误差；

- 判定器**不是**"保证"：它是基于现有四个数据集、三类检测器的经验关系；
- 必须同时报告三次校准失败（EXP-V3-01）作为方法背景，不得只报判定器；
