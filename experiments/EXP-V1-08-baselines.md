## 1. 设计（全部只用健康窗口训练）

四种检测器：A 3σ RMS 阈值 / B 马氏距离 / C One-Class SVM(RBF) / D Isolation Forest；
统一用**训练窗口分数的 99% 分位**作为报警线；IMS 用 0.25 s 窗、MFPT 用 1.0 s 窗。

## 3. Observation（事实）

1. **所有四种方法在 MFPT 上 AUROC 都是 1.000**、10% 误报预算下召回都是 1.000——
   判别"是否有故障"在本数据上不构成挑战，与 EXP-V1-02/06 一致。
2. 差异**全部出现在"健康记录上的误报"**：
   - A（3σ RMS）在三个 IMS 批次上稳定为 **2.4%**；
   - D（Isolation Forest）3.6%–4.8%；
   - B（马氏距离）4.8%–16.7% 且跨折方差大；
   - **C（One-Class SVM）27.4%–50.0%，是简单方法的 10–20 倍**。
3. 在 MFPT 上，D 的误报率为 0%，A 为 6.1%，B 与 C 分别为 54.5% 与 66.7%。
4. 计算耗时：A/B 约 0.1–0.3 ms，C 约 1–2 ms，D 约 200 ms（单折）。

## 4. Interpretation（初步解释，待审查）

1. **P1 不成立**：在这个"只给健康数据"的场景里，**现代单类方法并不比简单方法更可靠**；
   One-Class SVM 的误报控制最差，Isolation Forest 与简单阈值接近但略差于 A。
2. **单类方法对训练样本量高度敏感**：每个 IMS 折只有 11 个训练窗口；
   RBF One-Class SVM 在这种小样本下估计的正常区域很不稳定，
   这正好呼应我们此前"功效/样本量"的主线——**方法复杂度不能替代样本量**。
3. **P2 的"成立"是退化的**：所有方法召回都是 1.000，说明该项没有区分力；
   真正区分方法的是误报（P1）——这与 EXP-V1-07 的结论一致。
4. **P3 成立**：误报最低的方法在不同数据集上不同（IMS 上是 A，MFPT 上是 D），
   支持"没有普适最优检测器，必须报告评价条件"的论点。
5. 综合本实验与文献（Vieira 2026 面向有标签分类、未涉及功效/无监督），
   我们的贡献可以精确表述为：

   > 在**只有健康数据可训练**的泄漏安全协议下，简单检测器在**误报控制**上
   > 不逊于甚至优于现代单类基线；而评价这种差异必须报告**评价单元独立性与统计功效**。

## 5. Limitation

1. IMS 三个批次同属一类试验台，独立单元只有 3 个 → 不做显著性声称；
2. MFPT 只有 3 个正常文件，AUROC=1.0 属"易分"结果；
3. 未含深度模型（本轮范围外）；
4. One-Class SVM 只测了一组超参数（nu=0.01, RBF）；但**超参数未在测试集上调**，
   若要调参必须在训练/验证内进行（下一步可做）。

## 6. 结论（草案，待项目负责人审查）

- **P1 不成立、P3 成立** → 支持"简单方法在健康数据误报控制上具有竞争力，
  且方法优劣依赖数据"的论点；
- 该结论与 EXP-V1-07 的负结果、以及文献中的功效缺口（Scopus 43 / 69 篇）
  共同构成 V1.5 的主线：**评价协议（单元独立性 + 功效）比模型复杂度更重要**。
