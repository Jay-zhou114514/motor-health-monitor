项目负责人指出：主预注册中的 12 个 IMS 文件来自**同一试验台、相邻时间点**，
不构成独立样本。为降低伪重复程度，本次补充下载了 IMS 的另外两个试验批次。

## 3. 独立性如何计算（关键修订）

**独立单元 = 试验批次 / 物理试验台，而不是文件。**

- 同一批次内的文件是时间相邻的连续记录，**彼此相关**；
- 因此本实验的独立单元数量为：**3 个 IMS 批次 + 1 个 MFPT 试验台 = 4 个**，
  而不是 27 个文件；
- 任何把 27 个文件当作独立样本的合并统计（例如 pooled p 值）**只能作为描述性结果**，
  必须显式标注"忽略了批次内时间相关性"。

## 4. 分析结构（据此调整）

1. **批次内**：在 1st / 2nd / 4th 各自内部做 leave-one-file-out，得到每个批次的
   膨胀比、FP、收缩前后差异；
2. **批次间**：比较三个批次的**方向是否一致**（问题组的 Δ 膨胀比是否 > 0），
   报告为"3 个批次中 k 个一致"；
3. **跨试验台**：与 MFPT 的结果比较方向一致性；
4. 不做基于 27 个"独立文件"的假设检验。

## 5. 通道与窗口（保持修订 1 的约定）

- 主通道：**通道 1**（所有批次一致，避免挑选）；通道 2–4（或 8）仅作稳健性附注；
- 窗口：IMS 用 0.25 秒 / 步长 0.125 秒；MFPT 保持 1.0 秒 / 0.5 秒；
- 强制同时报告 0.5 秒窗的稳健性结果（修订 1 的约定不变）。

## 6. 判据不变

P1 / P2 / P3 与总体判定规则（支持 / 部分支持 / 不支持 / 无法判定）
沿用主预注册，不做放宽。仅把"折"的含义明确为"批次内折"，并在结论中
以批次为独立单元表述。

## 7. 记录但暂不执行的高价值数据源：Paderborn

调研结果（Zenodo 记录 `15845309`，CC-BY-4.0）：

- **K001–K006 为 6 个不同的"健康"物理轴承**，因此可提供 6 个**真正独立**的
  物理单元（优于 IMS 的批次级独立性）；
- 代价：每个 `.rar` 约 150–165 MB（6 个约 0.95 GB），且本机当前没有 RAR 解压工具；
- 触发条件：**仅当**本实验（3 个 IMS 批次）显示"膨胀 + 收缩缓解"方向一致、
  且需要更强的独立性证据时才下载；否则不下载，避免无谓的带宽消耗。

其他已排查来源（均不可用或不合适）：

- CWRU 官网无直接下载链接；HuggingFace 上的 CWRU CSV 为 100 MB–1 GB；
  GitHub 镜像只含 1 个正常文件；
- Ottawa 数据集的 GitHub 仓库只含代码，无数据文件；
- MFPT 官网未提供可直接下载的链接；
- Zenodo 全文检索"bearing fault dataset"命中大量无关记录，需按具体记录号访问。
