# EXP-V1-06 预注册（Pre-registration）

- 日期：2026-09-15
- 状态：**在运行实验之前冻结**（本文件先于任何结果提交，用于防止事后调整判据）
- 依据：研究计划 V1.3（EXP-V1-05 判定 B：保留 H1/H2 为 Level-B 工作假说，先补证据）

## 1. 目的

把 EXP-V1-05 的**后验观察**（"低方差方向上的标准化偏离幅度可能是区分问题组与对照组的因素"）
转化为**前瞻性、可检验的假设**：

1. V1.06-A：在未见过的正常文件上，该指标是否复现？
2. V1.06-B：在不使用测试数据的前提下，是否存在能稳定选出合理收缩强度 δ 的准则？

## 2. 冻结的指标定义（V1.06-A）

对某一折的训练正常窗口集合与特征组 g：

1. 由训练正常窗口计算均值 μ_g 与经验协方差 Σ_g（最大似然，除以 n）。
2. 对 Σ_g 做特征分解，特征值升序 λ₁ ≤ … ≤ λ_p，v_min 为 λ₁ 对应的单位特征向量
   （符号规范化：绝对值最大的分量为正）。
3. **标准化投影幅度**（本实验唯一使用的指标，不再寻找新指标）：

```text
s(x) = |(x − μ_g) · v_min| / √λ₁
```

4. 每个折、每个特征组报告：
   - 被留出正常文件窗口的 s 中位数
   - 故障文件窗口的 s 中位数
   - 距离膨胀比 = 被留出正常窗口距离中位数 / 阈值（阈值 = 训练窗口距离的 99% 分位）
   - FP / FPR / F1

**该定义一经提交不得修改。** 若必须修改，须另开"预注册修订"文件并说明原因。

## 3. 折的设计（V1.06-A / B 共用）

三折 leave-one-normal-file-out 轮换：

| 折 | 训练正常文件 | 被留出的正常文件 | 测试异常文件 |
| --- | --- | --- | --- |
| F1 | baseline_1, baseline_2 | baseline_3 | 5 个故障文件 |
| F2 | baseline_1, baseline_3 | baseline_2 | 5 个故障文件 |
| F3 | baseline_2, baseline_3 | baseline_1 | 5 个故障文件 |

- 特征组（与 EXP-V1-05 相同，不新增）：RMS + kurtosis（对照）、RMS + centroid（问题组）、
  crest + centroid（反例组）。
- 窗口：1.0 秒、步长 0.5 秒（与之前一致）。
- 阈值只用训练窗口确定；被留出正常文件与故障文件只用于评价。

## 4. 预定义预测与判定规则（V1.06-A）

| 编号 | 预测 | 判定 |
| --- | --- | --- |
| P1 | 问题组的 s（被留出正常文件）高于对照组，且在 3 个折中至少 2 个成立 | 成立 / 不成立 |
| P2 | 各折中"三组的 s 排序"与"膨胀比 / FP 排序"一致（Spearman 或排位一致） | 成立 / 部分成立 / 不成立 |
| P3 | 问题组的 s 与膨胀比在 3 折间同向变化 | 成立 / 不成立 |

总体判定：

- **支持**：P1 与 P2 均成立。
- **部分支持**：P1 成立、P2 不成立（或反之）。
- **不支持**：P1 不成立。
- **无法判定**：折间结果矛盾且样本量不足以区分。

## 5. 预定义的 δ 选择准则（V1.06-B）

δ 候选网格：0.00 ~ 1.00，步长 0.01。

| 编号 | 准则 | 定义（全部只用训练数据） |
| --- | --- | --- |
| C1 | empirical | δ = 0 |
| C2 | loo_window | 最大化训练窗口级留一高斯对数似然的 δ |
| C3 | ledoit_wolf | Ledoit–Wolf 解析收缩强度 |
| C4 | file_loo | 最大化"留一训练文件"高斯对数似然的 δ（文件级留一，不使用测试数据） |
| C5 | cond_target | 使条件数 ≤ 100 的最小 δ；若已 ≤ 100 则 δ = 0 |

预测：

| 编号 | 预测 |
| --- | --- |
| Q1 | 至少一个准则在 3 折中都选出 δ > 0（稳定非零） |
| Q2 | 该准则在问题组把膨胀比降到 < 1.0，且不明显增加对照组的 FP |
| Q3 | 不同准则选出的 δ 差异较大（说明选择准则本身不稳定） |

判定：

- **支持 H2**：Q1 与 Q2 成立。
- **部分支持**：Q1 成立但 Q2 不成立，或反之。
- **不支持**：没有任何准则在 3 折中稳定选出 δ > 0。

## 6. 不可声称的内容（预先声明）

即使结果支持，也不得声称：

- 最优 δ；
- 普适的 δ 选择方法；
- 跨设备 / 跨工况泛化；
- 普遍解决 Mahalanobis 误报膨胀。

原因：只有 3 个折、3 个正常文件、单一数据集。
