# EXP-V1-10 预注册：模型选择过程不确定性（量化）

- 日期：2026-09-17
- 状态：**在运行实验之前冻结**（本文件先于任何 EXP-V1-10 结果提交）
- 依据：V1.6 三层框架的 Layer 2/3；把 EXP-V1-09 的单点观察（33%）升级为可量化实验

## 1. 研究问题

> 在小样本、normal-only 的轴承异常检测中，**内部模型选择过程**本身有多稳定？
> 它的不稳定性**是否传导到最终报告的性能**上？

## 2. 设计（固定测试集 + 重复重采样）

**测试集固定**：从 IMS 1st_test 的 12 个健康文件中固定留出 **2 个文件**（索引固定，见脚本常量），
全程只用于最终评估，**绝不参与任何超参选择**。

其余 **10 个文件**用于重复的内部选择过程：

对 r = 1 … R（R = 50）：

1. 从 10 个文件中随机抽取 **7 个作为 fit 集**、**3 个作为 validation 集**（固定随机种子序列）；
2. 在 fit 集上拟合候选配置，用 validation 集计算 FP rate；
3. 选择 validation FP rate 最低的配置（并列取更保守者）；
4. 在固定测试集（2 个文件）上评估该配置，记录测试 FP rate；
5. 记录：被选配置、validation FP、test FP、拟合次数与耗时。

**对照**：

- 3σ RMS（无选择过程）在**同一固定测试集**上的 FP rate（作为"零选择方差"参考）；
- iForest 固定默认配置（`n_estimators=200, max_samples=0.8`，**不搜索**）在同一测试集上的 FP rate。

## 3. 指标

| 维度 | 指标 |
| --- | --- |
| Selection stability | 模态配置占比、被选配置的**不同取值个数**、归一化熵 |
| Performance | 测试 FP rate 的均值 / 标准差 / 极差 |
| Selection sensitivity | 权重：模态占比 < 50% 或不同配置 ≥3 个即视为高敏感 |
| Selection cost | 拟合次数、总耗时 |
| 关联 | 选择不稳定度与测试 FP 波动之间的 Spearman 相关（描述性） |

## 4. 预定义预测与判定

| 编号 | 预测 |
| --- | --- |
| P1 | 被选 iForest 配置的模态占比 < 50%，或不同配置数 ≥ 3（即选择过程不稳定） |
| P2 | 测试 FP rate 在 R 次重复间的标准差 ≥ 2 个百分点（即不稳定性传导到性能） |
| P3 | 3σ RMS 在同一测试集上的 FP rate 为**单一确定值**（无选择方差） |

总体判定：

- **支持**：P1 与 P2 均成立 → "模型选择过程本身就是不确定性的来源"（Layer 3 论点成立）；
- **部分支持**：仅其一成立；
- **不支持**：均不成立 → 撤回 Layer 3 的强调，只保留 Layer 1/2。

## 5. 分辨率与限制（预先声明）

- 测试集仅 2 个文件 × 7 窗口 = 14 个窗口 → **测试 FP rate 分辨率为 1/14 ≈ 7.1%**；
- 因此 P2 的"2 个百分点"阈值在该分辨率下**可能无法被可靠观测**；
  若出现"标准差 < 7.1% 但非零"的情况，必须按分辨率限制解读，**不得宣称稳定性**；
- 独立单元仍是单一试验台；不做显著性声称；
- 若 IMS 2nd/4th（6 文件）样本不足，仅作附注，不作主分析。
